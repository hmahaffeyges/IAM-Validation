== 2. Momentum of a closed craft: its own field exerts no net force (Eq. pr_noforce) ==
F_A + F_B = -(G'(u) + G'(-u)): zero for every u iff G' is odd, i.e. G even
even kernel 1/|u|: F_A + F_B = 0
even kernel Yukawa exp(-2|u|)/|u|: F_A + F_B = 0
even kernel Gaussian exp(-u^2): F_A + F_B = 0
kernel with an odd part exp(-u^2)(1+u): F_A + F_B = 2*(2*u**2 - 1)*exp(-u**2) (nonzero: a static kernel with an odd part breaks the third law)
40 sources aboard, kernel 1/r: |sum of all forces| = 1.15e-13 ; Yukawa:  7.03e-14

== 4. Negative mass pair (Bondi): self-acceleration with momentum and energy conserved ==
acceleration of + body along +x: G*m/r**2 ; of - body along +x: G*m/r**2 ; equal: True
total momentum m_+ v + m_- v = 0 ; total kinetic energy = 0
== 5. Active and passive gravitational mass: self-force of a pair (Eq. pr_selfforce) ==
net force on the pair = -G*(m_a1*m_p2 - m_a2*m_p1)/r**2 = G m_p1 m_p2 (m_a2/m_p2 - m_a1/m_p1)/r^2 : True
LLR bound on S(Al,Fe): 4e-12 (Bartlett & Van Buren 1986), 3.9e-14 (Singh et al. 2023)
