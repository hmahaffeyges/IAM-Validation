\chapter{The report}\label{ch:report}

\section{What a report is}

A report is one specimen's reading and everything needed to check it. Chain v3 writes it as one self-contained HTML page rendered from the run's
bundle (\texttt{chain/\allowbreak{}MethylPhys\_Interface/\allowbreak{}report\_v3.py}). A banner at the top states the build and that it is not a diagnostic test.
The sections follow the stages.

The gauge marker is drawn from $A_{\rm rel}$ whenever the tare produced one. Untared isolated neutrophils are drawn against their own floor and labelled untared.
Untared whole blood has no gauge position; the number is printed and the reader is told to supply references.

\section{What a report does not say}

The report does not name a condition, and it states its own state words only: \emph{Normal}, \emph{above Normal}, \emph{below Normal}, \emph{untared}. Covariates
supplied with a run (\texttt{--covariate}) are kept in the custody record, the bundle and the ledger, and no stage reads them. Because the bundle block of the
page shows the bundle, a covariate supplied as free text appears there. A render-time vocabulary guard on the v3 page, failing on condition names and cohort
vocabulary, is not yet built. \openprob

\section{Refusals are printed}

Everything the chain declines to do appears with the reason: a quarantined array (no page; the run stops), a refused platform, a composition not solved, a
neutrophil fraction below the read line, too few identity sites measured, a reading left untared, a methylated-site mean past the entropy ceiling, and an IAM-A
refused for its pipeline or for too few opportunities. The rule is that a reader should never have to infer what the instrument did not measure.

\section{The report as a laboratory record}

Each run writes, beside the page, the bundle as JSON and one row in an evidence ledger: run number, specimen, platform and array type, intake verdict, floor and
reference versions, neutrophil fraction, $A$, state, $A_{\rm rel}$, tare method and number of references, noise index, detection limit, C-score and, when present,
IAM-A with its pipeline. The intake record in the bundle carries the integrity hash of the IDAT pair. A reading is reproducible if a second laboratory with the same
IDATs, the same references and the same frozen files obtains the same numbers. The v3 bundle does not yet carry the chain's commit or the checksum of each frozen
file read, which a second laboratory needs to show it ran the same instrument. \openprob
