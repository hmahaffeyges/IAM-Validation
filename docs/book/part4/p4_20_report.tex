\chapter{The report}\label{ch:report}

\section{What a report is}

A report is one specimen's readings and everything needed to check them. It is rendered from a single bundle that records every input file with
its SHA-256, every constant with the file it came from, and every stage's output. It has seventeen tabs in two kinds: \emph{specimen} tabs, which
change with the specimen, and \emph{reference} tabs, which describe the instrument and are the same on every report.

\section{What a report does not say}

The report does not name a condition. Its measurement tabs are scanned at render time against two lists: condition names, and cohort vocabulary
(percentile, healthy range, cohort, age-matched, AUC, sensitivity and similar). A hit on a live measurement tab stops the render. The same guards run
over the Standard Operating Procedure, the Operations Manual and the paper before every change reaches the repository (Chapter~\ref{ch:discipline}).
Words that name what is being refused (``no band'', ``no population'') are allowed where they refuse.

\section{Refusals are printed}

Everything the chain declines to do appears on the report with the reason: a quarantined array, a tier withheld because the specimen is not whole
blood, a cell printed without a tier because its fraction is too small, a flag on a reading whose identity loci were built from corrected sequencing
data. The rule is that a reader should never have to infer what the instrument did not measure.

\section{The report as a laboratory record}

The Run tab carries what a second laboratory needs to reproduce the reading: the chain's commit, the checksum of every input, and the commands. The
Files tab carries the checksum of every runtime file the chain read. A reading is reproducible if a second laboratory with the same IDATs and the same
commit obtains the same numbers, and the report carries everything needed to check that.

\section{The report on the second atlas}

The v2 reader writes a reading per cell with fraction, interval, $A$ and tier, and runs as a preview beside the commissioned chain. It is not yet wired
into the report renderer. The switch-over wires it in, regenerates every derived document, and re-renders the reference report from the same array, so
that the report tabs describe the atlas that produced them.
