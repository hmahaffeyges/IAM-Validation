\chapter{Type Ia supernovae in the dual-sector picture: $\Lambda$CDM distances with a locally calibrated $H_0$}\label{ch:dsvalidation}

\section*{Summary}
The Informational Actualization Model (IAM) proposes that late-time cosmic expansion couples differently to photons versus matter, and reads the Hubble
tension through sector-specific expansion rates \interp. This dual-sector framework makes a critical, testable prediction: Type Ia supernovae (SNe), as
matter-based distance indicators hosted in galaxies, should probe the matter sector. The hypothesis is tested here using the complete Pantheon+ dataset
(1588 SNe, $0.01<z<2.26$) through three independent analyses: (1) SNe with the Planck (photon-sector) $H_0$ prior, (2) SNe with the SH0ES (matter-sector)
$H_0$ prior, and (3) SNe with no $H_0$ constraint. With the absolute magnitude $M$ free, the three analyses reach the same minimum for any $H_0$: the
supernova magnitudes do not choose between the photon-sector rate ($H_0=67.4$ km\,s$^{-1}$\,Mpc$^{-1}$) and the matter-sector normalization
($H_0=73.04$ km\,s$^{-1}$\,Mpc$^{-1}$), which comes from the Cepheid calibration of $M$ \derived. Critically, SNe distances maintain $\Lambda$CDM
geometric consistency ($\beta_{\rm distance}=-0.035$, $68\,\%$: $-0.065$ to $0.000$, full covariance) \observed, validating IAM's prediction that
sector-specific coupling primarily affects structure growth ($f\sigma_8$) rather than photon propagation geometry; the $\beta$ term applied to supernova
distances is excluded ($\Delta\chi^2=+23.6$) \calc. In the dual-sector reading, Planck ($H_0=67.4$, photon sector) and SH0ES ($H_0=73.04$, matter sector)
both measure correctly---they probe different physical quantities \interp. The dual-sector phenomenology maps directly onto the standard modified gravity
parametrization: matter perturbations obey $\mu(a)=H^2_{\Lambda\rm CDM}(a)/[H^2_{\Lambda\rm CDM}(a)+\beta_mE(a)H_0^2]<1$ (suppressed growth), while
photon deflection remains unmodified ($\Sigma=1$), preserving CMB consistency. This $\mu<1$, $\Sigma=1$ framework is independently testable with existing
Boltzmann solvers (CAMB/CLASS) and upcoming survey parametrizations (DES, Euclid, CMB-S4). All results are independently reproducible in under two minutes
via the complete Python code of Section~\ref{sec:dsv_code}.

\section{Introduction}\label{sec:dsv_question}
The Hubble tension---a persistent $>5\sigma$ discrepancy between cosmic microwave background (CMB) measurements yielding $H_0=67.4\pm0.5$
km\,s$^{-1}$\,Mpc$^{-1}$~\cite{Planck2018VI} and local distance ladder measurements giving $H_0=73.04\pm1.04$ km\,s$^{-1}$\,Mpc$^{-1}$~\cite{Riess2022}---represents
a fundamental crisis in cosmology \observed. Proposed solutions including early dark energy~\cite{Kamionkowski2023}, modified gravity~\cite{Amendola2018},
and interacting dark sectors~\cite{DiValentino2021} each face significant challenges in simultaneously resolving $H_0$ tensions while maintaining
consistency with other cosmological observables.

The Informational Actualization Model (IAM) proposes an alternative framework: late-time expansion couples differently to photons versus matter through
sector-dependent parameters $\beta_\gamma$ and $\beta_m$ (Chapters~\ref{ch:theory} and \ref{ch:dual}). The coupling constant $\beta_m=\Omega_m/2=0.15765$
is derived from the virial partition of gravitational energy (Chapter~\ref{ch:virial}), yielding zero free parameters beyond $\Lambda$CDM \prediction.
Full Boltzmann validation via 15 converged Planck MCMC chains (Level~1 MGCAMB + Level~2 modified CAMB Fortran) gives $\Delta\chi^2=+0.54$ relative to
$\Lambda$CDM, with $\sigma_8$ suppressed from 0.809 to 0.800 and a dual-sector Hubble split: $H_0(\mathrm{photon})=67.16$ km\,s$^{-1}$\,Mpc$^{-1}$
($0.37\sigma$ from Planck), $H_0(\mathrm{matter})=72.26$ km\,s$^{-1}$\,Mpc$^{-1}$ ($0.75\sigma$ from SH0ES) \measured. CMB acoustic scale constraints
force $\beta_\gamma<0.0039$ ($95\,\%$)---establishing a sector ratio $\beta_\gamma/\beta_m<0.025$ where photons couple at least $40\times$ more weakly
than matter (Chapter~\ref{ch:dsnote}, Figure~\ref{fig:beta_gamma}) \calc.

This dual-sector framework faces an obvious and critical question: \emph{Is sector separation an ad-hoc theoretical assumption, or does independent
observational evidence demand it?} Type Ia supernovae (SNe) provide a direct test. As standardizable candles hosted in galaxies and calibrated through
local distance ladder methods, SNe measure cosmic distances across $0.01<z<2.3$. If sector separation is real, it should be possible to ask which
expansion history SNe probe---photon sector ($H_0\approx67.4$ km\,s$^{-1}$\,Mpc$^{-1}$) or matter sector ($H_0\approx73$ km\,s$^{-1}$\,Mpc$^{-1}$).

This is tested using the complete Pantheon+ dataset~\cite{Brout2022,Scolnic2022} through three complementary approaches:
\begin{description}
\item[Test A (Photon Hypothesis).] Constrain SNe to Planck's photon-sector $H_0=67.4\pm0.5$ km\,s$^{-1}$\,Mpc$^{-1}$ and determine best-fit $\beta$.
If SNe probe the photon sector, $\beta\to0$.
\item[Test B (Matter Hypothesis).] Constrain SNe to the SH0ES matter-sector $H_0=73.04\pm1.04$ km\,s$^{-1}$\,Mpc$^{-1}$ and determine best-fit $\beta$.
If SNe probe the matter sector, $\beta$ should match the SDSS/BOSS/eBOSS growth value or yield $\beta_{\rm distance}\approx0$ if geometric.
\item[Test C (Unconstrained).] Remove all $H_0$ priors and let SNe data alone determine both $H_0$ and $\beta$.
\end{description}
The results show what these fits can and cannot decide \derived. With $M$ free, $H_0$ and $M$ enter the magnitudes only as $M-5\log_{10}H_0$, so the
three tests share one minimum and cannot select $H_0$ (Section~\ref{sec:dsv_tests}). What the supernovae do measure is the shape of the Hubble diagram,
and the shape follows $\Lambda$CDM; the matter-sector normalization enters through the local calibration (Section~\ref{sec:dsv_geometry}).

\section{Theoretical framework}\label{sec:dsv_framework}
\subsection{IAM dual-sector parameterization}
The IAM matter-sector expansion rate introduces sector-dependent late-time coupling (the global background Friedmann equation remains standard
$\Lambda$CDM; the modification operates within the perturbation equations, Chapters~\ref{ch:dual} and \ref{ch:level2}):
\begin{equation}
H_m^2(a)=H_0^2\left[\Omega_ma^{-3}+\Omega_\Lambda+\beta E(a)\right],
\label{eq:dsv_Hm}
\end{equation}
where $E(a)=\exp(1-1/a)$ is the activation function that vanishes at early times ($E(a\to0)\to0$) and reaches unity today ($E(a=1)=1$) \derived\
(Appendix~\ref{app:der:activation}; sympy check of $E(1)=1$, of the inflection at $a=1/2$ and of the maximum of $dE/d\ln a$ at $a=1$ in
\texttt{verify\_dual\_sector\_chapters.py}, Section~0). The coupling parameter $\beta$ is sector-specific:
\begin{align}
\text{photon sector (CMB, photon propagation):}\quad &\beta_\gamma<0.0039\quad(95\,\%,\ \text{acoustic-scale fit}), \label{eq:dsv_bg}\\
\text{matter sector (local $H_0$, structure growth):}\quad &\beta_m=\Omega_m/2=0.15765\quad(\text{zero free parameters}). \label{eq:dsv_bm}
\end{align}
The first is \calc\ (\texttt{verify\_beta\_gamma.py}); the second is \prediction, with $\Omega_m=0.3153$ from Planck~\cite{Planck2018VI}.
Level~2 MCMC posterior: $\Omega_m=0.3166\pm0.0065$, implying $\Omega_m/2=0.1583\pm0.0032$, consistent with the fixed $\beta_m$ at $0.2\sigma$ ($\beta_m$
is fixed, not sampled, in every chain) \calc.

This yields sector-specific Hubble parameters:
\begin{align}
H_0(\text{photon})&=67.16\pm0.47\ \text{km\,s}^{-1}\,\text{Mpc}^{-1}\quad\text{(Level 2 posterior)}, \label{eq:dsv_H0g}\\
H_0(\text{matter})&=H_0\sqrt{1+\beta_m}=67.161\times1.0759=72.26\pm0.50\ \text{km\,s}^{-1}\,\text{Mpc}^{-1}. \label{eq:dsv_H0m}
\end{align}
Eq.~\eqref{eq:dsv_H0g} is \measured; Eq.~\eqref{eq:dsv_H0m} is \calc\ and follows from Eq.~\eqref{eq:dsv_Hm} at $a=1$, where $E=1$:
$H_m^2(1)=H_0^2(\Omega_m+\Omega_\Lambda+\beta_m)=H_0^2(1+\beta_m)$ in a flat universe \derived.

\subsection{Type Ia supernovae: the critical test}
SNe present a unique observational test because they measure \emph{both} $H_0$ normalization (through calibration with the local distance ladder)
\emph{and} the geometric distance--redshift relation (through the Hubble diagram shape). IAM predicts SNe should exhibit:
\begin{description}
\item[Prediction 1.] Matter-sector $H_0$ normalization from local calibration (Cepheids, TRGB) yielding $H_0=72.26$ km\,s$^{-1}$\,Mpc$^{-1}$ \prediction.
\item[Prediction 2.] $\Lambda$CDM geometric consistency ($\beta_{\rm distance}\approx0$) because IAM's primary effect is on structure growth (modified
$\Omega_m$ dilution affecting $f\sigma_8$), not photon propagation distances \prediction.
\end{description}
These predictions are testable through independent likelihood analyses constraining $H_0$ and $\beta$ parameters.

\subsection{Three test scenarios}
Three mutually exclusive hypotheses are constructed:
\begin{description}
\item[Scenario A (Photon).] SNe measure photon propagation geometry independent of matter coupling. Expectation: $H_0\approx67.4$ km\,s$^{-1}$\,Mpc$^{-1}$,
$\beta\approx0$.
\item[Scenario B (Matter).] SNe participate in matter-sector expansion through galaxy hosting and local calibration. Expectation: $H_0\approx73$
km\,s$^{-1}$\,Mpc$^{-1}$, $\beta\approx0$ (geometric) or $\beta\approx0.16$ (full matter coupling).
\item[Scenario C (Mixed).] SNe exhibit intermediate or complex behavior. Expectation: $H_0\approx70$ km\,s$^{-1}$\,Mpc$^{-1}$, $\beta$ intermediate.
\end{description}

\section{Data and methodology}\label{sec:dsv_data}
\subsection{Pantheon+ dataset}
The Pantheon+SH0ES compilation~\cite{Brout2022,Scolnic2022} is used, comprising 1701 light curves of spectroscopically confirmed Type Ia supernovae
(1550 distinct supernovae) spanning $0.001<z<2.26$. Following standard practice, the low-redshift objects ($z<0.01$) are excluded to avoid peculiar
velocity contamination, yielding 1588 SNe in the Hubble flow ($0.01<z<2.26$) with median photometric uncertainty $\sigma_{m_b}=0.21$ mag \observed\
($0.212$, the diagonal error column of the release). The full-covariance fits below use the collaboration's own Hubble-flow selection,
$z_{\rm HD}>0.01$, which contains 1590 SNe.
The corrected apparent magnitude $m_b^{\rm corr}$ of the release gives the distance modulus
\begin{equation}
\mu_{\rm obs}=m_b^{\rm corr}-M, \label{eq:dsv_mbcorr}
\end{equation}
where $M$ is the absolute magnitude (fitted parameter).

\subsection{IAM luminosity distance}
The theoretical magnitude in IAM is
\begin{equation}
m_b^{\rm model}(z)=M+5\log_{10}\!\left[\frac{d_L(z)}{10\ {\rm pc}}\right]=M+5\log_{10}\!\left[\frac{d_L(z)}{1\ {\rm Mpc}}\right]+25, \label{eq:dsv_mu}
\end{equation}
where the luminosity distance is
\begin{equation}
d_L(z)=(1+z)\int_0^z\frac{c\,dz'}{H(z';\beta)} \label{eq:dsv_dL}
\end{equation}
and
\begin{equation}
H(z;\beta)=H_0\sqrt{\Omega_m(1+z)^3+\Omega_\Lambda+\beta E\!\left(\frac{1}{1+z}\right)}. \label{eq:dsv_Hz}
\end{equation}
The Planck 2018 baseline cosmology is adopted: $\Omega_m=0.315$, $\Omega_\Lambda=0.685$~\cite{Planck2018VI}. Eq.~\eqref{eq:dsv_Hz} puts the matter-sector
rate of Eq.~\eqref{eq:dsv_Hm} into the distances; $\beta=0$ is $\Lambda$CDM.

\subsection{Chi-squared analysis}
For each test configuration, the quantity minimised is
\begin{equation}
\chi^2=\sum_{i=1}^{1588}\left(\frac{m_{b,i}^{\rm corr}-m_b^{\rm model}(z_i;\Omega_m,H_0,\beta,M)}{\sigma_{m_b,i}}\right)^2+\chi^2_{\rm prior}, \label{eq:dsv_chi2}
\end{equation}
where $\chi^2_{\rm prior}$ implements external constraints:
\begin{equation}
\text{Test A: }\chi^2_{\rm prior}=\left(\frac{H_0-67.4}{0.5}\right)^2\ \text{(Planck)},\quad \text{Test B: }\chi^2_{\rm prior}=\left(\frac{H_0-73.04}{1.04}\right)^2\
\text{(SH0ES)},\quad \text{Test C: }\chi^2_{\rm prior}=0\ \text{(unconstrained)}. \label{eq:dsv_priors}
\end{equation}
Free parameters are: $\Omega_m\in[0.20,0.40]$, $H_0\in[60,75]$ km\,s$^{-1}$\,Mpc$^{-1}$, $\beta\in[-0.30,+0.30]$, $M\in[-20.0,-18.0]$ mag.
Minimization employs the Nelder--Mead simplex algorithm with 5000 maximum iterations and adaptive step sizing. A simplex does not guarantee a global
minimum, and because of the exact degeneracy derived below every minimum in this chapter is checked by minimising $M$ analytically and scanning
$(\Omega_m,\beta)$ on a grid.

\paragraph{Full covariance.} The diagonal errors of Eq.~\eqref{eq:dsv_chi2} omit the correlated systematics. The geometry results of
Section~\ref{sec:dsv_geometry} therefore also use the full statistical-plus-systematic covariance $C$ of the release, the Hubble-flow selection of the
collaboration ($z_{\rm HD}>0.01$, 1590 supernovae, peculiar-velocity-corrected redshifts with the heliocentric redshift in the $(1+z)$ factor), and
$\chi^2=\Delta^{\rm T}C^{-1}\Delta$ with $\Delta=m^{\rm corr}-m^{\rm model}$.

\subsection{The $H_0$--$M$ degeneracy}\label{sec:dsv_degeneracy}
Write the luminosity distance as $d_L=(c/H_0)(1+z)\,I(z;\Omega_m,\beta)$, with the dimensionless integral $I=\int_0^z dz'/\sqrt{\Omega_m(1+z')^3+\Omega_\Lambda+\beta E}$.
Then Eq.~\eqref{eq:dsv_mu} becomes
\begin{equation}
m_b^{\rm model}=\left(M-5\log_{10}H_0\right)+5\log_{10}\!\left[c\,(1+z)\,I(z;\Omega_m,\beta)\right]+25 .
\end{equation}
$H_0$ and $M$ enter only through the single combination $\mathcal M\equiv M-5\log_{10}H_0$. Any change $H_0\to\lambda H_0$ is undone exactly by
$M\to M+5\log_{10}\lambda$ (sympy: the difference is identically zero). With $M$ free the supernova part of Eq.~\eqref{eq:dsv_chi2} is therefore
independent of $H_0$, and the prior term of Eq.~\eqref{eq:dsv_priors} is satisfied at no cost by setting $H_0$ equal to the prior value \derived.
The minimum over $\mathcal M$ is analytic. With weights $w_i=\sigma_{m_b,i}^{-2}$ and residuals $r_i=m_{b,i}^{\rm corr}-5\log_{10}[c(1+z_i)I(z_i)]-25$,
\begin{equation}
\hat{\mathcal M}=\frac{\sum_iw_ir_i}{\sum_iw_i},\qquad \chi^2_{\min}(\Omega_m,\beta)=\sum_iw_i\left(r_i-\hat{\mathcal M}\right)^2 ;
\end{equation}
with the full covariance, $\hat{\mathcal M}=\mathbf 1^{\rm T}C^{-1}\mathbf r/\mathbf 1^{\rm T}C^{-1}\mathbf 1$ and
$\chi^2_{\min}=(\mathbf r-\hat{\mathcal M}\mathbf 1)^{\rm T}C^{-1}(\mathbf r-\hat{\mathcal M}\mathbf 1)$ \derived. The supernova magnitudes constrain
only $\Omega_m$ and $\beta$, through the shape of $I(z)$.

\textbf{Result.} The fit drives $\beta$ to the lower parameter boundary ($-0.30$) \calc. The prior itself is met exactly ($H_0=67.40$); the boundary value

measurements.

\textbf{Interpretation.} The SN data do not reject the photon-sector expansion rate: the same valley, with the same minimum, is reached for every $H_0$
(Section~\ref{sec:dsv_degeneracy}). Test~A therefore gives no evidence against Scenario~A \derived.

\section{Physical interpretation}\label{sec:dsv_geometry}
\subsection{Matter-sector $H_0$ normalization}
The supernova results require careful interpretation. They do \emph{not} contradict the virial-derived $\beta_m=0.15765$ (consistent with the Level~2
Planck chain). Rather, they reveal that $\beta$ manifests differently in different observables:

\textbf{$H_0$ normalization.} The local distance ladder (Cepheids + SNe) measures
\begin{equation}
H_0(\text{local})=H_0(\text{base})\times\sqrt{1+\beta_m}=72.26\ \text{km\,s}^{-1}\,\text{Mpc}^{-1}. \label{eq:dsv_H0local}
\end{equation}
This is an \emph{overall calibration} effect---the local expansion rate includes matter-sector coupling, yielding higher $H_0$ than the CMB \prediction.

\textbf{Distance--redshift geometry.} The \emph{shape} of $d_L(z)$ is
\begin{equation}
d_L(z)\propto(1+z)\int_0^z\frac{dz'}{H(z')} . \label{eq:dsv_shape}
\end{equation}
For $\beta_m=0.157$ with $E(a)$ activation placed in $H(z)$, the geometric modification to $d_L(z)$ is \emph{not} small: at fixed $H_0$, $d_L$ changes by
$-6.5\,\%$ at $z=0.1$ and $-2.3\,\%$ at $z=2$; with the normalization absorbed by $M$, the shape changes by $+2.3\,\%$ ($0.048$ mag) at $z=0.5$,
$+3.6\,\%$ ($0.077$ mag) at $z=1$ and $+4.8\,\%$ ($0.101$ mag) at $z=2$, relative to $z=0.05$ \calc. That is far above Pantheon+ precision. Therefore SNe
carry the matter-sector \emph{normalization} through their calibration while maintaining $\Lambda$CDM \emph{geometric shape}: their distances do not
follow $H$ with the $\beta$ term (next paragraph).

\subsection{Growth vs.\ geometry dichotomy}
IAM's primary physical effect is \emph{growth suppression} through $\Omega_m$ dilution:
\begin{equation}
\Omega_m(a;\beta)=\frac{\Omega_ma^{-3}}{\Omega_ma^{-3}+\Omega_\Lambda+\beta E(a)}<\Omega_m(a;0). \label{eq:dsv_Omdil}
\end{equation}
Dividing by $\Omega_m(a;0)=\Omega_ma^{-3}/(\Omega_ma^{-3}+\Omega_\Lambda)$,
\begin{equation}
\frac{\Omega_m(a;\beta)}{\Omega_m(a;0)}=\frac{H^2_{\Lambda\rm CDM}(a)}{H^2_{\Lambda\rm CDM}(a)+\beta E(a)H_0^2}=\mu(a), \label{eq:dsv_Omdil_mu}
\end{equation}
so the diluted matter fraction is the same factor as the $\mu(a)$ of Section~\ref{sec:dsv_musigma} \derived\ (sympy, Section~0 of the script): $0.864$ at
$z=0$, $0.982$ at $z=1$. This modified $\Omega_m(a)$ enters the growth equation, producing growth suppression and yielding $\sigma_8(\text{IAM})=0.800$
(Level~2 Planck chain) versus $\Lambda$CDM's 0.809 \measured. SDSS/BOSS/eBOSS $f\sigma_8(z)$ measurements~\cite{Howlett2015,Alam2017,Alam2021} directly
probe this growth modification at the amplitude fixed by $\beta_m=0.15765$ (Chapters~\ref{ch:latetime} and \ref{ch:level2}).

In contrast, SNe measure \emph{photon propagation distances}, which integrate $H(z)$ but do not directly probe structure growth. The background $H(z)$
that the distances integrate is unmodified, which explains $\beta_{\rm distance}\approx0$ despite $\beta_{\rm growth}=0.157$ \interp.

\subsection{Sector separation: what the supernovae test}
\interp\ The three tests were built so that they could have falsified dual-sector separation. Specifically:
\begin{itemize}
\item if SNe probed the photon sector, Test A would yield $\beta\approx0$ with a good fit;
\item if SNe were sector-agnostic, Test C would yield $H_0\approx70$ km\,s$^{-1}$\,Mpc$^{-1}$ (intermediate);
\item if sector separation were an artifact, Tests A, B, C would show inconsistent results.
\end{itemize}
With $M$ free none of these outcomes can occur, because each test reaches the same minimum for any $H_0$ (Section~\ref{sec:dsv_degeneracy}). What the
supernovae can decide is the shape, and the shape follows $\Lambda$CDM. The normalization is decided by the calibrators: SH0ES gives $73.04\pm1.04$,
$0.75\sigma$ above the predicted $72.26$; the tip of the red giant branch gives $70.39\pm1.94$~\cite{Freedman2025}, $0.96\sigma$ below it \observed.

\section{Comparison to alternative interpretations}\label{sec:dsv_alternatives}
\subsection{Could this be SNe systematics?}
Systematic errors in SNe photometry, dust corrections, or absolute magnitude calibration might bias $H_0$ measurements. Such errors move $M$, and through
it the ladder $H_0$; the Hubble-flow fits alone cannot diagnose them, for the reason of Section~\ref{sec:dsv_degeneracy}, while the shape of the Hubble
diagram is protected by the full covariance used above. The external statement on the normalization is the SH0ES measurement itself: SH0ES independently
measures $H_0=73.04$ using \emph{the same SNe} calibrated on Cepheids~\cite{Riess2022} \observed.

\subsection{Could SNe be special?}
One might argue SNe are unique---neither purely photon nor matter sector. However \interp:
(1) \emph{Local calibration:} the SNe Hubble diagram normalization comes from Cepheid distances measured in nearby galaxies. These are matter-based
indicators tied to local expansion.
(2) \emph{Galaxy hosting:} SNe occur in star-forming galaxies---matter structures participating in cosmic structure formation.
(3) \emph{SH0ES classification:} the SH0ES collaboration explicitly uses SNe + Cepheids as a local, matter-based distance ladder~\cite{Riess2022},
consistent with the matter-sector interpretation.
The distances themselves are measured with light, and the Hubble-flow shape follows $\Lambda$CDM. How a distance built from photons inherits the
matter-sector normalization is stated as an open problem in Chapter~\ref{ch:dual} \openprob.

\subsection{Modified gravity alternative?}
Modified gravity theories that change the background typically predict \emph{distance deviations} from $\Lambda$CDM---precisely what is \emph{not} observed
($\beta_{\rm distance}\approx0$) \observed. Modified-gravity models in the $\mu$--$\Sigma$ form do, however, separate growth ($\mu$) from lensing ($\Sigma$):
in $f(R)$ gravity in the quasi-static regime $\Sigma=1$ with $\mu$ between $1$ and $4/3$~\cite{PogosianSilvestri2008}; normal-branch DGP and most
scalar--tensor theories give $\mu>1$; the self-accelerating branch of DGP gives $\mu<1$ with $\Sigma=1$, but it carries a ghost~\cite{Koyama2007} and is in
tension with CMB, supernova and $H_0$ data~\cite{Fang2008}. The dual-sector picture gives $\mu<1$ with $\Sigma=1$, an unmodified background, and an
amplitude fixed in advance.

\subsection{Early dark energy alternative?}
Early dark energy (EDE) modifies pre-recombination physics to increase the $H_0$ inferred from the CMB~\cite{Kamionkowski2023}. However:
(1) EDE does not predict sector-dependent $H_0$---it attempts to reconcile Planck and SH0ES by modifying the sound horizon.
(2) EDE worsens the $S_8$ tension~\cite{Hill2020}, whereas the dual-sector coupling lowers $S_8$: the Level~2 chain gives $S_8=0.822\pm0.011$ against
$0.830\pm0.011$ for $\Lambda$CDM with the same code and data, a shift of $0.8\sigma$ toward the weak-lensing values \measured.
(3) EDE provides no prediction for SNe behavior, whereas IAM predicts matter-sector normalization with $\Lambda$CDM geometry; the geometry part is borne out
here.

The present SNe analysis tests the matter side of the split from a different direction: without assuming sector separation, it asks what the supernovae

\subsection{Implications for Hubble tension resolution}
\interp\ The traditional Hubble tension assumes Planck and SH0ES measure the \emph{same} $H_0$ but disagree---a crisis requiring new physics, systematics,
or measurement error. IAM reframes this: \emph{Planck and SH0ES both measure correctly---they probe different sectors.}
Planck (CMB photons): $H_0=67.16$ km\,s$^{-1}$\,Mpc$^{-1}$ in the Level~2 chain (photon sector, $\beta_\gamma\approx0$).
SH0ES (Cepheids + SNe): $H_0=73.04$ km\,s$^{-1}$\,Mpc$^{-1}$ (matter-sector normalization; predicted $72.26$).
On this reading the ``tension'' is neither error nor new physics; it is a measurement of sector-dependent late-time expansion. The SN Hubble flow neither
confirms nor rejects the reading: it fixes the geometry, and the normalization rests on the calibrators. Which observable reads $H_0^{\rm matter}$ without
passing through a distance built from light is the open problem of Chapter~\ref{ch:dual} \openprob.

\end{enumerate}

\subsection{Connection to modified gravity parametrization}\label{sec:dsv_musigma}
The dual-sector phenomenology admits a precise mapping onto the standard $\mu$--$\Sigma$ modified gravity parametrization widely used in observational
cosmology~\cite{Amendola2018}. In this framework, the Poisson equation governing matter perturbations is modified by $\mu(a)$, while photon deflection
(weak lensing, CMB) is governed by $\Sigma(a)$:
\begin{equation}
k^2\Phi=-4\pi G\,\mu(a)\,\rho_m\delta_m a^2,\qquad k^2(\Phi+\Psi)=-8\pi G\,\Sigma(a)\,\rho_m\delta_m a^2. \label{eq:dsv_poisson}
\end{equation}
IAM's matter-sector coupling maps to
\begin{equation}
\mu(a)=\frac{H^2_{\Lambda\rm CDM}(a)}{H^2_{\Lambda\rm CDM}(a)+\beta_mE(a)H_0^2},\qquad\Sigma(a)=1, \label{eq:dsv_mu_sigma}
\end{equation}
where $E(a)=\exp(1-1/a)$ is the activation function \derived\ (Chapter~\ref{ch:dual}, Eq.~\eqref{part2:eq:mu}). At $z=0$, $\mu=0.864$: the effective Newton
constant for matter is lower by $1-\mu_0=\beta_m/(1+\beta_m)=13.6\,\%$, which is not the change in growth; growth integrates $\mu$ over time, and
$f\sigma_8$ is lower by $4.25\,\%$ at $z=0$ (Chapter~\ref{ch:latetime}) \calc. At $z=1$, $\mu=0.982$; and $\mu\to1$ for $z\gtrsim3$ ($1-\mu<4\times10^{-4}$),
recovering $\Lambda$CDM \calc. The condition $\Sigma=1$ ensures that photon geodesics, CMB lensing, and the acoustic scale $\theta_s$ are
unmodified---precisely the photon-sector constraint $\beta_\gamma<0.0039$.

This mapping has three important consequences. First, IAM predictions have been validated through full Boltzmann solvers: 12 Level~1 chains via MGCAMB
and 3 Level~2 chains via modified CAMB Fortran, all consistent with the full Planck 2018 likelihood ($\Delta\chi^2=+0.54$ best-fit at Level~2;
Chapter~\ref{ch:dual}) \measured. Second, upcoming surveys (DES Year~6, Euclid, Rubin-LSST) will constrain $\mu(a)$ and $\Sigma(a)$ independently;
Euclid's sensitivity to this $\mu(z)$ is as stated in Section~\ref{sec:lt_euclid}. Third, the specific functional form $\mu(a)<1$ with $\Sigma=1$
distinguishes IAM from most modified gravity theories, which predict $\mu>1$ ($f(R)$, normal-branch DGP) or correlated $\mu$ and $\Sigma$
(scalar--tensor); it is shared with the self-accelerating branch of DGP, and what is specific to IAM is the redshift form of Eq.~\eqref{eq:dsv_mu_sigma}
with its amplitude fixed by $\Omega_m/2$ \derived.

\section{Conclusions}\label{sec:dsv_conclusions}
A rigorous empirical test of the dual-sector expansion framework has been presented using 1588 Type Ia supernovae from Pantheon+. Three analyses---with
the Planck (photon) prior, the SH0ES (matter) prior, and no $H_0$ constraint---together with the full-covariance fit lead to the following conclusions:
\begin{enumerate}
\item \textbf{SN distances follow $\Lambda$CDM geometry:} the Hubble-flow shape gives $\beta_{\rm distance}=-0.035$ ($68\,\%$: $-0.065$ to $0.000$) with
the full covariance, as Prediction~2 requires \observed.
\item \textbf{The $\beta$ term applied to SN distances is excluded:} $\Delta\chi^2=+23.6$ at Planck's $\Omega_m$; it can be offset only with $\Omega_m=0.41$
\calc.
\item \textbf{The magnitudes do not measure $H_0$:} with $M$ free, $H_0$ and $M$ enter only as $M-5\log_{10}H_0$; Tests A, B and C share one minimum
($\chi^2=721.12$) for any $H_0$ \derived. The matter-sector normalization $73.04$ comes from the Cepheid calibration; the prediction is $72.26$
($-0.75\sigma$) \observed.
\item \textbf{Growth vs.\ geometry dichotomy:} SNe carry the matter-sector \emph{$H_0$ normalization} (calibration effect) while maintaining
\emph{$\Lambda$CDM distances} (geometric consistency), as IAM's prediction that $\beta$ primarily affects structure growth ($f\sigma_8$) rather than
photon propagation requires \interp.
\end{enumerate}
\interp\ In the dual-sector reading, the Hubble tension reflects not measurement error or exotic new physics, but sector-dependent late-time expansion:
Planck ($H_0=67.16$ in the chain, photon sector) and SH0ES ($H_0=73.04$, matter sector) both measure correctly---they probe different physical quantities
in a structure-coupled cosmology.

\section{Analysis code and data}\label{sec:dsv_code}
\paragraph{Pantheon+ data.} The complete Pantheon+SH0ES dataset is publicly available at \url{https://github.com/PantheonPlusSH0ES/DataRelease}; specific file
\texttt{Pantheon+\_Data/\allowbreak{}4\_DISTANCES\_AND\_COVAR/\allowbreak{}Pantheon+SH0ES.dat}. The covariance used in Section~\ref{sec:dsv_geometry} is
\texttt{Pantheon+SH0ES\_STAT+SYS.cov} in the same folder. The tests read columns 5, 9 and 10 of the data file ($z_{\rm CMB}$, $m_b^{\rm corr}$ and its
diagonal error) and keep $0.01<z_{\rm CMB}<2.5$ (the code's cut), which selects the 1588 objects of $0.01<z<2.26$.
\paragraph{Python requirements.} Python $\ge3.8$, NumPy $\ge1.18$, SciPy $\ge1.5$; install via \texttt{pip install numpy scipy}.
\paragraph{Runtime.} Each test completes in 10--35 seconds on standard hardware (a 2020 laptop with an M1 chip); total runtime for all three tests is under two
minutes.
\paragraph{Reproducibility.} All results can be independently verified by running the scripts on the public Pantheon+ dataset. No proprietary software,
data, or computational resources are required. The complete verification, with the full covariance and every check of this chapter, is
\texttt{docs/\allowbreak{}verification/\allowbreak{}scripts/\allowbreak{}verify\_dual\_sector\_chapters.py}.
\paragraph{Complete code for Tests A, B and C.} The three tests differ only in the prior term; one program runs all three (the model magnitude uses $d_L$ in
Mpc with the $+25$ of Eq.~\eqref{eq:dsv_mu}):
\begin{verbatim}
import numpy as np
from scipy.optimize import minimize
c_km_s = 299792.458
z_sne, mb_obs, dmb_obs = [], [], []
for line in open("Pantheon+SH0ES.dat").readlines()[1:]:
    parts = line.split()
    # cut at 2.5: keeps all 1588 Hubble-flow SNe (largest zCMB = 2.26)
    if len(parts) >= 10 and 0.01 < float(parts[4]) < 2.5:
        z_sne.append(float(parts[4]))        # zCMB
        mb_obs.append(float(parts[8]))       # m_b_corr
        dmb_obs.append(float(parts[9]))      # m_b_corr_err_DIAG
z_sne, mb_obs, dmb_obs = map(np.array, (z_sne, mb_obs, dmb_obs))
def activation(a):
    return np.exp(1.0 - 1.0 / a)
def H_IAM(z, Om0, H0, beta):
    a = 1.0 / (1.0 + z)
    return H0 * np.sqrt(Om0 * a**-3 + (1.0 - Om0) + beta * activation(a))
def dL_IAM(z, Om0, H0, beta):                 # Mpc
    z_arr = np.linspace(0.0, z, 500)
    return (1.0 + z) * np.trapz(c_km_s / H_IAM(z_arr, Om0, H0, beta), z_arr)
def chi2_IAM(params, prior):
    Om0, H0, beta, M = params
    if not (0.2 < Om0 < 0.4 and 60 < H0 < 75 and -0.3 < beta < 0.3
            and -20 < M < -18):
        return 1e10
    m = np.array([M + 5 * np.log10(dL_IAM(z, Om0, H0, beta)) + 25
                  for z in z_sne])
    pr = 0.0 if prior is None else ((H0 - prior[0]) / prior[1])**2
    return np.sum(((mb_obs - m) / dmb_obs)**2) + pr
for name, prior, H0start in (("A, Planck prior", (67.4, 0.5), 67.4),
                             ("B, SH0ES prior", (73.04, 1.04), 73.04),
                             ("C, no prior", None, 70.0)):
    r = minimize(chi2_IAM, [0.315, H0start, 0.0, -19.3], args=(prior,),
                 method="Nelder-Mead", options={"maxiter": 5000})
    Om0, H0, beta, M = r.x
    print(name, Om0, H0, beta, M, r.fun, r.fun / (len(z_sne) - 4))
\end{verbatim}
A simplex stops where the flat $H_0$ direction and the $\Omega_m$--$\beta$ valley leave it, so the $H_0$ it returns carries no information on the sector
(Section~\ref{sec:dsv_systematics}); the minima of Tables~\ref{tab:dsv_testA}--\ref{tab:dsv_compare} are those of the analytic-offset grid in the
verification script.
