\chapter{Reproducing every number and figure}\label{appendices:app:repro}

Every figure is produced by \texttt{make\_figures.py}, shipped with the source of this book, from constants, the frozen floors, and chain output files in its
\texttt{data/\allowbreak{}} folder (the 37 reference cells, the tare per-array file, the identity-loci build, the serial change floor and the preview readings). It needs NumPy,
SciPy, pandas and Matplotlib. The principal numbers:

\begin{Verbatim}[breaklines,breakanywhere,fontsize=\footnotesize]
import numpy as np, math
kB, NA, T = 1.380649e-23, 6.02214076e23, 310.15; R = kB*NA
H = lambda b: -(b*np.log2(b) + (1-b)*np.log2(1-b))
print(kB*T*math.log(2))                 # 2.968e-21 J per bit
print(54000/(R*T), 54000/(R*T)/math.log(2))   # M = 20.94 ; 30.21 bits per ATP
print(19.6e6*kB*T*math.log(2)/(54000/NA))     # 6.5e5 ATP per methylome copy
# closed-form floor from a class's reference entropies, Eq. (7.2)
h = H(np.array([0.745, 0.735, 0.730, 0.720, 0.715, 0.740]))   # example values
print((h**2).sum()/h.sum())
# slope of A at the immune floor point
b = 0.7318; print(math.log2((1-b)/b)/0.838889)             # -1.73 per unit beta
# Smarr for one solar mass
hbar, c, G, M = 1.054571817e-34, 2.99792458e8, 6.67430e-11, 1.98847e30
TH = hbar*c**3/(8*math.pi*G*M*kB); S = 4*math.pi*G*M**2*kB/(hbar*c)
print(TH*S, M*c**2/2)                    # equal
\end{Verbatim}
