\chapter{Reproducing the cell numbers and figures}\label{appendices:app:repro}

The cell numbers of Part~\ref{part:4} come from chain v3, in \texttt{Biological\_Physics/\allowbreak MethylPhys/\allowbreak chain/} of the repository
\url{https://github.com/hmahaffeyges/IAM-Validation}. A specimen is read through the chain's own entry point,
\texttt{MethylPhys\_Interface/\allowbreak run\_sample.py} with \texttt{--engine v3}, from its raw IDAT pair: intake, calibration, the platform check,
composition (whole blood), Met-A, the C-score, the tare and the report (Chapter~\ref{ch:chain}). Every frozen value the chain reads is a file in
\texttt{chain/\allowbreak Runtime~Matrices/}: the Met-A neutrophil reference and its 6,000 sites (\texttt{Met\_A\_Floors/\allowbreak metA\_floors\_v1\_3.json}, with the
held-out readings in \texttt{metA\_floors\_\allowbreak v1\_3\_loo.csv}), the C-score baseline (\texttt{Met\_A\_Floors/\allowbreak neutrophil\_reference\_\allowbreak v1\_1.json}),
the IAM-A position (\texttt{IAM\_A\_Positions/\allowbreak iama\_positions\_\allowbreak v1.json}) and the intake lines (\texttt{Intake/\allowbreak intake\_thresholds\_\allowbreak v1.json}).
The end-to-end acceptance run, \texttt{Biological\_Physics/\allowbreak MethylPhys/\allowbreak chain\_tests/\allowbreak run\_chain\_acceptance.py}, sends the purified
neutrophil arrays and the known mixtures of GSE110554 and blood arrays from a second laboratory through that same entry point; it needs those IDAT files
and atlas v2 on local disk, and its results are in \texttt{chain\_tests/\allowbreak chain\_acceptance.csv}. The Part~\ref{part:4} figures are built by the scripts in
\texttt{docs/\allowbreak book/\allowbreak figscripts/} (for example \texttt{fig\_chain\_v3\_flow.py} and \texttt{fig\_eps0\_T.py}). The principal numbers, run from the
repository root:

\begin{Verbatim}[breaklines,breakanywhere,fontsize=\footnotesize]
import json, math
import numpy as np, pandas as pd
kB, NA, T = 1.380649e-23, 6.02214076e23, 310.15; R = kB*NA
H = lambda x: -(x*np.log2(x) + (1-x)*np.log2(1-x))
print(kB*T*math.log(2))                          # 2.968e-21 J per bit
M = 54000/(R*T); print(M, M/math.log(2))          # 20.94 ; 30.21 in Landauer units
print(19.6e6*kB*T*math.log(2)/(54000/NA))         # 6.5e5 ATP: Landauer floor of one methylome copy
Ehold = 3.41; eps0 = 1/(1+math.exp(Ehold))
print(Ehold/M, eps0)                              # phi = 0.163 ; eps0 = 0.032
print(H(eps0), 1.099*H(eps0), 1/1.099)            # 0.204 ; 0.224 ; 0.910
print(1/0.330263, 1/(1.099*H(eps0)))              # A_max: 3.03 (Met-A) ; 4.45 (IAM-A)
d = "Biological_Physics/MethylPhys/chain/Runtime Matrices/"
f = json.load(open(d + "Met_A_Floors/metA_floors_v1_3.json"))["platforms"]["EPIC"]["neutrophils"]
print(f["floor"], f["n_ref"], f["n_sites"])         # 0.330263 ; 6 ; 6000
loo = pd.read_csv(d + "Met_A_Floors/metA_floors_v1_3_loo.csv")
print(loo.A_loo.min(), loo.A_loo.max(), loo.A_loo.std())   # 0.983 ; 1.045 ; 0.020
p = json.load(open(d + "IAM_A_Positions/iama_positions_v1.json"))["cells"]["neutrophils"]
print(p["P"], p["P_range"], p["pipeline"])         # 1.099 ; [1.0841, 1.1079] ; loyfer_pat_v1
print(json.load(open(d + "Met_A_Floors/neutrophil_reference_v1_1.json"))["healthy_clustering_median"])   # 1.1104
\end{Verbatim}
