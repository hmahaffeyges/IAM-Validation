\paragraph{What this book is.} IAM stands for the Informational Actualization Model. In physics a model is a specific, testable set of
equations inside an accepted framework, as $\Lambda$CDM is inside general relativity. IAM is a model in that sense: it describes how
informational actualization, the irreversible writing of a record at $k_BT\ln2$ per bit, is responsible for the classical world, and IAM's law
states where that cost enters the physics already in place. It is a model of reality as it already exists, not a new theory set against general
relativity, quantum mechanics or the standard cosmological model. Those are correct descriptions of their own places, and every result they have
earned stands. The Einstein equations are untouched. Nothing is replaced. It is the piece Jacobson's derivation left open, added to work already
done: one quantity is counted that was always there, and counting it shows that results from separate fields describe the same event. Everywhere
after this page it is simply IAM.

\paragraph{The event.} Every irreversible transition from a quantum superposition to a classical record pays $k_BT\ln2$ per bit to the nearest
