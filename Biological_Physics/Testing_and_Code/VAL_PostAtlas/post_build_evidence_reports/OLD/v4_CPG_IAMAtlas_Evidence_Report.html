Section 1

Instructions for future AI sessions and outside researchers

Read this section before anything else in this document. The Reproducibility Triple (CHK-7.6 absolute) plus three additional rules govern what gets into this report and what gets excluded.

Rule 1 — Reproducibility quadruple (mandatory per VAL block)

Every VAL block in Section 3 onwards MUST link or contain all four of the following. A VAL block missing any of the four is INVALID and must not be cited as evidence.

  • Cohort source: GSE accession + direct GEO URL + source paper citation + cohort SHA-256 manifest path.
  • Script: path in repo to the Python script that runs the VAL + script SHA-256.
  • Sealed prereg: PREREG.md path + SHA-256 + seal date (before any data access).
  • Sealed results: results.json + per_sample.csv path + SHA-256 + outcome.md path.
Rule 2 — CPG-native tools only

Post-build VALs use the IAMAtlas-native production stack: Walther IAM Deconvolver, IAMAtlas REBUILD, iamatlas_a_scoring.py (Stage 2), iamatlas_mahalanobis_scoring.py (Stage 2.5), CPG-native disease panels discovered via the per-CpG residual map on IAMAtlas-deconvolved cohorts. External published panels (Xu-538, Rule A 7-CpG, FAM19A4-miR124, PDAC-324) and external published atlases (Loyfer 25-tile, EpiSCORE, Salas 6-cell, UniLIFE 19-cell) are NOT production scoring tools. They were used in build/calibration and live in the RETIRED report.

Rule 3 — Confirmation vs exploratory separation

Family A (foundation) and Family B (per-card) are CONFIRMATION VALs: each one is load-bearing for a CPG claim. Family C (exploratory enrichment) and Family D (educational replication) are NOT load-bearing — they exist for additional context, publication, or methodological comparison. Do not mix the two families when computing validation tier claims.

Rule 4 — Vault discipline

The Recipe (Jacobson → virial → Landauer derivation chain, H_min derivation, MCMC class-assignment rule, hierarchical Bayesian build protocol) is vault content. It does not appear in this report. The published A-score formula A = H(β) / H_min(class) is the public-facing equation; H_min values per class are quoted as constants without derivation. This is the Coca-Cola model — the can is public, the recipe is vault.

Section 2

Scope — what is in this report and what is not

The CPG (Cellular Performance Gauge) is the diagnostic instrument of cellular astro-genetics, built on the IAMAtlas REBUILD reference posterior (483,092 CpGs × 115 cell types × 8 architecture classes). It reads systemic cellular signal at sub-cellular resolution from a single methylation array, anchored to architectural information-theoretic floors (H_min per class).

This report contains only post-IAMAtlas-build evidence. The IAMAtlas itself was built and calibrated against pre-build atlases and disease panels (Loyfer 25-tile, EpiSCORE, Salas, UniLIFE, Xu-538, and others); that build history and the validation evidence supporting it live in RETIRED_Evidence_Report.html and RETIRED_VAL_inventory_report.md. The retired record stands as the lineage of how the instrument was bootstrapped. It does not count as CPG production evidence.

Post-build evidence is organized into four families, mirroring v1_CPG_VAL_Inventory_Report.md:

  • Family A — Foundation confirmation VALs (CPG-VAL-001 → CPG-VAL-007): the seven methods that established that the CPG architecture itself produces real, replicating signal against sealed cohort anchors. Detailed in Section 3 below.
  • Family B — Per-card confirmation VALs: one series per CPG disease card. As of v4: Family B(AD-immune) CPG-VAL-008 through CPG-VAL-014 substantively sealed on three AD cohorts. Section 4.
  • Family C — Exploratory enrichment VALs: additional tests against new sealed cohorts (e.g. blinded acquisitions). Future, not yet running.
  • Family D — Educational replication VALs: selective re-runs of RETIRED-era findings using CPG-native tools, for methodological comparison and publication. Future.

The Mahalanobis distance is the multi-dimensional analog of the CMB community's joint posterior ellipsoid (banana degeneracy / hyper-volume). Mathematically it weights each axis of departure by the inverse covariance of the healthy reference, so axes with low HC variance count more than axes with high HC variance. The result is a single number per patient with statistical meaning: "how far is this patient from the healthy reference hyper-volume on a scale that respects the natural variation of healthy people." The top-10 axis decomposition (returned alongside the distance) tells the clinician WHICH cell types most drive the patient's distance — basophils z=+1.20, kidney z=+0.96, plasma cells z=+0.93, pancreatic acinar z=+0.93, pancreatic duct z=+0.91 for the breast pre-diagnostic case centroid. This is the universal departure-from-healthy summary that every CPG report leads with regardless of which disease card is being scored — the Mahalanobis distance fires for any condition that shifts cellular architecture from healthy, with the decomposition pointing to the cellular origin of the shift.

This VAL is the architectural pivot point for the post-build CPG era. The instrument no longer depends on any external disease-trained panel (Xu-538, Rule A, FAM19A4-miR124, PDAC-324) for its scoring keys. Instead, each disease card has its own native CPG panel discovered by running the production Walther IAM Deconvolver on a known case-vs-HC cohort and identifying the CpGs where the disease residual replicates across cohorts. The 1,389 NEW candidate CpGs that don't appear in the RETIRED Xu-538 panel are the more interesting finding — they identify disease-specific loci that classical panel-discovery methods (logistic regression with FDR control on raw β values) miss because those classical methods don't subtract cellular composition first. By subtracting the cellular composition reconstruction, CPG isolates the disease signal from the much-larger cell-composition signal and surfaces loci that were drowned out before. The CPG_breast_panel_v1 build (CPG-VAL-008) is the immediate downstream action of this VAL.

CPG-VAL-004: Per-CpG bimodality loss map (Sarle BC) — 2026-05-29

What it testsWhether per-CpG distribution-shape changes (loss of bimodality in cases relative to HC) constitute an independent disease signature class orthogonal to mean-shift Cohen's d. MethodFor each CpG, compute Sarle's bimodality coefficient BC = (skew² + 1) / (kurt + 3(n-1)² / ((n-2)(n-3))) separately for the case and HC distributions. Bimodal in HC: BCHC > 5/9 ≈ 0.556. Lost in case: BCcase < 5/9. Loss-of-bimodality CpGs satisfy both conditions. Headline result821 CpGs bimodal in HC across the cohort. 396 of those lose bimodality in cases. 35 CpGs are double-confirmed: loss-of-bimodality AND concordant residual map signal from CPG-VAL-003. Outcome codeO1_PRIMARY_VALIDATED — a novel biomarker class (distribution-shape change without mean shift) detected at biologically meaningful scale. StatusAnalysis complete. Formal VAL sealing pending. ArtifactBiological_Physics/atlas_vault/pipeline_runtime_matrices/card_residual_maps/breast_epic/bimodality_map.csv

Loss-of-bimodality is the "density fluctuation" analog from cosmology applied to the methylome (§3.12 of the EDEAR Physics Roadmap). DNA methylation at most regulatory CpGs is fundamentally bimodal — samples cluster near β ≈ 0 or β ≈ 1, with intermediate values rare. Disease drift can manifest not as a mean shift (where Cohen's d sees it) but as a SPREAD shift — samples drift toward intermediate β values, losing the clean two-peak structure. The 396 loss-of-bimodality CpGs found here would be invisible to a classical mean-vs-mean analysis. The 35 double-confirmed CpGs (bimodality loss AND concordant residual) are the highest-confidence candidate biomarkers in the breast pre-dx cohort — they show both the mean shift AND the distribution-shape change, two independent signatures pointing at the same loci.

This is the "isotropy / preferred-axis" test from cosmology (§3.10) applied to the methylome. The conclusion mirrors the CMB observational fact: large-scale isotropy holds, with a small handful of "anomalies" that turn out to be biologically interpretable. The chr6 MHC enrichment is the most informative deviation — the MHC/HLA region encodes the molecular machinery of antigen presentation and T-cell receptor recognition, and CPG-VAL-005 independently surfaced a T-cell suppression axis. CPG-VAL-007: Dipole subtraction audit — age-axis projection-and-subtract — 2026-05-29

What it testsFor each class A-score: is the case-vs-HC signal a true case-specific effect, or is it driven by cohort age differences confounding the comparison? Project out the principal age-correlated axis in HC space and re-test. MethodFrom the HC cohort only, regress each class A-score on chronological donor age. The vector of age-regression coefficients defines the "age axis" in A-score feature space. For every patient (case and HC), compute the projection scalar along this axis and subtract that projection × axis from the patient's standardized A-score vector. Re-test case-vs-HC Cohen's d on the age-axis-cleaned A-scores. Re-compute the Mahalanobis hyper-volume distance on the cleaned vectors. StatusAnalysis complete. Formal VAL sealing pending.

This VAL is the CMB-analog "dipole subtraction" (§3.7) — the principal contaminant axis is identified and projected out before the signal of interest is measured. In CMB observation, the dipole signal from Earth's motion through the cosmic background is the largest single anisotropy and must be subtracted before higher-order anisotropies can be measured. In CPG analysis, age-related methylation drift is the largest single contaminating axis and projecting it out reveals which case-vs-HC signals survive and which were age artifacts. The biological conclusions: (1) the architecture-wide immune class A-score is partly an age proxy at this cohort scale, BUT the disease-specific immune panel CpGs (the kind that will populate CPG_breast_panel_v1 from CPG-VAL-003) are a different observable and may behave differently — CPG-VAL-009 will test this directly. (2) Terminal, stromal, and stem_pluri class A-scores are GENUINELY case-specific — they are not age artifacts and contribute real disease signal. (3) The Mahalanobis hyper-volume distance benefits from dipole subtraction in the smaller cohort (GSE51032 improves by +0.25 in d) — confirming that universal departure-from-healthy is the right summary when properly age-cleaned.

AD-immune Family B consolidated interpretation

Disease-trained panel outperforms universal Mahalanobis ~3× on AD. The 7-CpG Rule A panel (AUC 0.84) outperforms the universal Mahalanobis hyper-volume distance (AUC 0.62) for AD discrimination. This is the OPPOSITE of breast pre-dx, where universal Mahalanobis (d=+1.876/+2.097) BEATS the disease-trained Xu-538 panel by +0.75. AD's signal is targeted (immune-class architectural disruption) and disease-trained panels work better. Breast pre-dx's signal is broad-architectural and universal metrics work better. Operational scoring routing matters: don't mix them up.

GIFT three-disease specificity arm is the most rigorous discriminator. Same Mahalanobis metric, three biologically distinct signatures: AD d=+0.68 (hyper-volume departure outward), FTD d=+0.28 (intermediate), PSP/CBD d=−0.38 (BELOW_NORMAL — architectural compaction). Primary 4R tauopathies (PSP/CBD) show OPPOSITE direction from AD on the universal architectural readout. This is the strongest evidence that IAM-architectural distance is biologically meaningful — it discriminates direction-of-departure not just magnitude.

Cross-platform replication is real but attenuated at universal scale. Per-cell-type biology replicates (Eosino AddNeuroMed d=−0.46 vs AIBL d=−0.43). Universal Mahalanobis on AddNeuroMed: d=−0.006 (null) vs AIBL +0.20. The 450K coverage gap (86-95% of EPIC CpGs hit) attenuates the universal hyper-volume metric but not the per-cell-type metric. This is platform, not biology.

PC1 in AIBL is the T-cell axis — different rank from breast pre-dx (PC2). Same biology, different rank because cohort composition differs (breast pre-dx population vs AIBL at-diagnosis population). The hypothesis must be "the T-cell axis will be a top PC," not "PC2 will be the T-cell axis."

Tier breakpoints are breast-calibrated and don't move for AD's modest universal signal. AIBL immune tier distribution: HC 88% NORMAL, AD 88% NORMAL — the universal-tier system doesn't discriminate AD because the thresholds were set against breast pre-dx where the disturbance is larger. AD's operational scoring routes through the 7-CpG Rule A panel, not the universal tier system. Tier system stays as universal screen; per-disease panels override for known disease patterns.

Lessons learned worth carrying forward across all future cards

(Full canonical list lives in MASTER_TRACKER §0.1; this is the AD+breast learning summary.)

  1. Operational scoring routing matters. AD's signal is targeted (immune-class) — disease-trained 7-CpG Rule A panel (AUC 0.84) beats universal Mahalanobis (AUC 0.62). Breast pre-dx's signal is broad-architectural — universal Mahalanobis (d=+1.876/+2.097) beats disease-trained Xu-538 by +0.75. Don't mix them up.
  2. Cross-method check (Walther vs NILC v2) is a robust biological-substrate signature, not a method-specific artifact. Strong ρ on dominant blood compartments across all five cohorts tested. Non-blood classes correctly return near-zero in both methods (noise dominates).
  3. 450K coverage gap (86-95%) attenuates universal Mahalanobis but per-cell biology replicates. Document this for any future cross-platform validation. This is platform, not biology.
  4. PC rank differs across cohorts but biology is the same. AIBL PC1 = T-cell axis; breast pre-dx PC2 = T-cell axis. The hypothesis must be "the T-cell axis will be a top PC," not "PC2 will be the T-cell axis."
  5. Tier breakpoints are breast-calibrated. AD's modest universal signal doesn't move them (HC 88% NORMAL vs AD 88% NORMAL on AIBL immune). Breast pre-dx GSE51032 puts both arms at BELOW_NORMAL — operational readout for breast pre-dx is Mahalanobis-primary, not tier-primary. Tier system stays as universal screen; per-disease panels override.
  6. GIFT three-disease specificity is the strongest discriminator. AD +0.68, FTD +0.28, PSP/CBD −0.38. Same metric, three distinct signatures, with primary 4R tauopathies showing OPPOSITE direction. IAM-architectural distance discriminates direction-of-departure not just magnitude.
  7. Stage 1 anchor reproduction is the integrity gate. AIBL +0.615 vs +0.624; AddNeuroMed +0.317 vs +0.332; GIFT EXACT matches; GSE51032 +2.088 vs +2.097. Run BEFORE any new analysis on a cohort. If it fails, stop and debug pipeline — don't proceed.
  8. Cellular age SATURATED is expected for blood substrate vs multi-tissue reference. Non-blood classes (terminal, stromal, stem_pluri) saturate. First-client report layer needs SATURATED-handling logic.
  9. NILC independent view corroborates findings at compositional level. NILC sees AD as shifting fractions away from immune toward progenitor/cycling (corroborates per-cell immune drop). NILC sees breast pre-dx as stromal+secretory expansion + immune suppression (corroborates per-cell stromal/breast_BE/immune findings).
  10. Strict additive over incremental — never modify existing rows or sections. Always archive vN in OLD/ and append in vN+1. The mistake that motivated this rule: prior versions of this Evidence Report and the inventory carried "TO BUILD" placeholder rows for AD VALs that became stale and confusing once the actual AD work landed. v4 onwards: every changelog edit cleans the old framing.
