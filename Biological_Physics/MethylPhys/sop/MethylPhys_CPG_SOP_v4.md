# Official IAM Chain Operator Guide (chain v4)

How to run the chain as it is built: what to install, what files go where, the commands, what the chain declines, and what it writes. Each stage is described from above; the line-by-line deep dive of every stage, gate and function is the Chain Decoder in the Official IAM Operations Manual: Instrument Diagnostics and Chain Decoder (`manual/`).

Generated by `build_sop_v4.py` from the chain's own files. Do not edit by hand. Where this document and the code differ, the code is what runs.

**The chain's job:** one sample goes in; every commissioned instrument reads it inside its commissioned scope, reads outside it with a plain note saying it has not yet been tested there, or declines with its reason. Research use only; not a diagnostic test.

## 2. Install

From a fresh clone of the repository, Python 3.11:

```
git clone https://github.com/hmahaffeyges/IAM-Validation.git && cd IAM-Validation/Biological_Physics/MethylPhys/chain
python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt
```

Stage 1 needs the Illumina manifest; methylprep downloads it on first use into `$HOME/.methylprep_manifest_files/`. Without it the run stops with `ENVIRONMENT_MISSING_MANIFEST` (exit 3) and the array is not judged.

## 3. Check the chain (one command)

```
python3 release_check_v4.py
```

It runs every check of the chain, including real arrays from the chain's test data, planted samples for each instrument, and the checksum of every frozen file below. Every check must pass; a run that does not pass is not a commissioned chain.

## 4. Read one sample

Arrays (a raw IDAT pair, Illumina EPIC v1):

```
cd MethylPhys_Interface
python3 run_sample.py --grn S_Grn.idat --red S_Red.idat --specimen "whole blood" --id S001 --out S001.html
```

Isolated neutrophils: `--specimen "isolated neutrophils"`. Optional: `--sex F|M`, `--age`, recorded when given. Same-run healthy references for the median tare: `--ref-table refs.csv`, three or more healthy arrays read on the same run, with column `A` (their Met-A reading) and column `C` (their C-score), each from that array's own report bundle.

Sequencing (whole-genome bisulfite), against the sample's own reference:

```
python3 run_sample.py --pat S.pat.gz --seq-cell "cd8 t cells" --id S002 --out S002.html
python3 run_sample.py --bam S.bam --ref-fasta hg19.fa --assembly hg19 --seq-cell "cd8 t cells" --id S003 --out S003.html
```

`--seq-cell` names the cell type; the sample-shape check has a healthy shape for 56 cell types: adipocytes, aorta endothelium, b cells, bladder epithelium, breast basal epithelium, breast luminal epithelium, cardiomyocyte, cd4 t cells, cd8 t cells, colon enteroendocrine, colon epithelium, colon fibroblasts, colon macrophages, cortical neurons, effector memory cd8 t cells, endometrium epithelium, erythrocyte progenitors, fallopien tubes epithelium, gastric antrum epithelium, gastric body epithelium, gastric fundus epithelium, heart fibroblasts, hepatocyte, kidney glomerular endothelium, kidney glomerular epithelium, kidney tubular endothelium, kidney tubular epithelium, lung alveolar endothelium, lung alveolar epithelium, lung alveolar macrophages, lung bronchus epithelium, lung interstitial macrophages, memory b cells, monocytes, naive cd4 t cells, naive cd8 t cells, nk cells, oligodendrocytes, pancreas endothelium, pancreatic acinar, pancreatic alpha, pancreatic beta, pancreatic delta, pancreatic duct, prostate epithelium, small intestine epithelium, smooth muscle, striated muscle, t central memory cd4, t effector cell cd8, t effector memory cd4, thyroid epithelium, tongue epithelium, tonsil palatine epithelium, tonsil pharyngeal epithelium, vascular saphenous endothelium.

## 5. What the chain declines, and why

- An EPIC v2 or 450K array: refused at intake with one sentence (no frozen Met-A reference for that platform).
- A failed array (Stage 0 quarantine): exit 2, no report.
- A sequencing sample whose shape is outside the healthy shape of its declared cell type, or with too few qualifying molecules: IAM-A declines and says why.
- A noisy array (the noise gate): the Met-A state is withheld and no gauge is drawn.

## 6. Outputs

- `S001.html`: the report. At a glance; cell shares (IAM-Deconvolver against IAM-Atlas v2.1); Met-A; the C-score with its HEALPix sky plate; IAM-A; the turning globe (the sample, its healthy reference, the difference and Met-A's departures, with a slider that fades the smaller differences; a picture, nothing scored from it); the technical record.
- `S001_bundle.json`: every stage's output, with the chain's commit.
- one row appended to `evidence_ledger.jsonl` beside the report.

## 9. Rules

- Synthetic first: every new test runs on planted data, read by the chain's exact rule, before any real data is opened.
- Sealed before read: a test's samples, rule and bars are committed before its data is downloaded; it is scored once.
- Clean clone: every chain change passes `release_check_v4.py` on a fresh clone, on a clean machine, before it is called tested.
- One reading per instrument; no lines beyond Normal are printed until they are measured on the gauge.

The earlier procedure, for chain v3, is kept as the record of how the chain was built: [MethylPhys_CPG_SOP_v3.md](MethylPhys_CPG_SOP_v3.md).
