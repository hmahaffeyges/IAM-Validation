# Chain commissioning — stage by stage, in switching order

**Goal:** every link accepted on record before any new disease cohort is scored. Acceptance = a named test on known inputs with the result written to `Record/`; a stage is COMMISSIONED only when its test passes from the repo on a machine that has never seen the project. Order is the chain order; nothing downstream is accepted while something upstream is open.

**End state:** one raw IDAT pair in → one final report out, every number on it carrying its surface, scale and band status, no number on it that any open item forbids. Then breast, CRC, prostate, pancreatic.
