# DEV_CORDB_01: a cord blood B-cell column for the IAM Sequencing Atlas (development)

`cordb_samples.csv`: the three sorted CD19+ umbilical cord blood donors of GSE116229 (GSM4914800, GSM4914801, GSM4914802; the leukemia study's own healthy comparison, open raw reads). Each is merged from the chunks `split_align.yml` already aligned (`chunksfrom`, `chunksalso`) and read once by the one command (`full=1`, specimen sorted cells). The sample list's `keep` column asks `erase_gh.sh` to keep, from the same merged molecules, the per-CpG count file made by the chain (`run_sample.py --build seq-pat-lbeta`, the format the Sequencing Atlas builder reads) and the Law Sphere counts on every unit (`--law-counts-out`). A column built from these files enters the atlas only through a gated edit with its tests (each donor held out in turn).
