# MethylPhys - the instrument

Everything the chain is and uses, in one place. Evidence lives beside it in `../Record/`; superseded material is
in `../RETIRED_2026-09/`. If you are reading this to run something, start at `doors/RUNBOOK.md`.

| directory | what is in it |
|---|---|
| `chain/` | the chain itself - [`cpg_conductor.py`](chain/cpg_conductor.py) orchestrates 18 files in stage order, plus `Runtime Matrices/` (48 reference and calibration files), the deconvolvers, the synthetic generator and the null runner |
| `chain/MethylPhys_Interface/` | the researcher interface: [`build_methylphys.py`](chain/MethylPhys_Interface/build_methylphys.py) renders one report from the conductor's output; [`run_sample.py`](chain/MethylPhys_Interface/run_sample.py) is the one-command entry point; [`build_chain_inventory.py`](chain/MethylPhys_Interface/build_chain_inventory.py) generates the parts list |
| `atlas/` | `IAMAtlasREBUILD.csv(.xz)` - 483,092 CpGs x 115 cell types with posterior mean, SD and interval per entry - its provenance record, the class archives and the array manifests |
| `runtime reference data` | `reference_data/` - the calibrated betas every measured constant was fitted on, four laboratories, published beside the constants rather than described |
| `kit/` | the reproduction kit: 40 guards and sealed procedures, [`release_check.py`](kit/release_check.py) runs them all in one command, [`finding_check.py`](kit/finding_check.py) gates a push |
| `sop/` | the chain-of-custody SOP. Its file references and reference table are generated by [`sop_repoint.py`](sop/sop_repoint.py) from the inventory |
| `manual/` | the engineering manual ([[Issue 003](manual/MethylPhys_CPG_Operations_Manual.pdf)](manual/MethylPhys_CPG_Operations_Manual.pdf)) and its build |
| `papers/` | the methods paper and the explainers |
| `plates/` | the figures: gauges, skies, the microwave-background comparison |
| `doors/` | [`RUNBOOK.md`](doors/RUNBOOK.md) (how to run it and the finding protocol), [`HANDOFF.md`](doors/HANDOFF.md), [`CHAIN_COMMISSIONING.md`](doors/CHAIN_COMMISSIONING.md) (every row and its state), [`COMPONENT_MAP.md`](doors/COMPONENT_MAP.md) |
| `hmin_calibration/` | the floor calibration - the MCMC chains, the bootstrap cross-check and their outputs |


**Checking this work?** [`doors/REVIEWER_MANIFEST.md`](doors/REVIEWER_MANIFEST.md) lists every file a reviewer can download - the chain, the H_min MCMC calibration, the runtime matrices, the atlas, every sealed procedure including the ones that failed - and states plainly what is *not* published and why.

## One command

```
cd chain/MethylPhys_Interface
python3 run_sample.py --grn SAMPLE_Grn.idat.gz --red SAMPLE_Red.idat.gz --age 58 --lab MYLAB --out report.html
```

A laboratory the chain has not commissioned has no zero and no sky scale, so the report prints NOT REPORTABLE with
the reason rather than a number. Commissioning one takes 40 healthy arrays of that laboratory through Stage 1 and
then `chain/lab_zero.py`; the procedure is in `doors/RUNBOOK.md`.

## What it reports

Whether this sample's cellular write process is operating within the healthy range for its age, by architecture
class, against a fixed physical zero. It names no condition, matches no pattern to any signature, and states no
age in years.

**Which substrate can this instrument read, and what is tested next:** [`doors/SUBSTRATE_STRATEGY.md`](doors/SUBSTRATE_STRATEGY.md).
