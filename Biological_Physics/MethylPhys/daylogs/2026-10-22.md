## What we set out to do

Test Met-A against IAM-Atlas v2.1 with the chain's same-run tare on an independent laboratory's healthy cells, and finish the open GitHub runs.

## What ran, and how each came out

- **Met-A against the atlas, tared on the same slide (GRP-014, DEV-METAA-ATLAS-01 exploration 6)** — _development_  
  An independent laboratory's healthy children's monocytes, read against the atlas's adult monocytes and tared against healthy monocytes run on the same slide: all 67 read Normal, and a planted 1 % loss of their pattern stands out at 3.6 times the healthy spread. Children given BCG at birth read Normal too.  
  _Why it matters:_ Met-A read against the atlas lets any cell type in the atlas be read, not only the ones with a purified-array reference; the same-run tare cancels the laboratory and age gaps.  
  [the record](../doors/DEV_METAA_ATLAS_01.md)
- **All ten reproductions pass on GitHub's machines (OTH-076)** — _audit_  
  The mouse reproduction ran across 19 GitHub machines and every read set came out identical to the committed run, so every reproduction a researcher can run now passes on GitHub's free machines, without the AWS account. One workflow runs all of them from a researcher's own copy of the repository.  
  _Why it matters:_ A result counts only when someone else can produce it again from the repository alone.  
  [the record](../reproduce/verified.json)
- **The C-Score's band test, rerun through the one command (COM-CSCORE-011)** — _audit_  
  Every reading and tare by run_sample.py from the raw arrays: the band holds again. One array fewer is scored, because Stage 0's bisulfite limit, set after the first scoring, now stops it.  
  _Why it matters:_ Everything is rerun through the one command, so a researcher replicates exactly what we ran.  
  [the record](../doors/data/CSCORE_COMMISSIONING/run_chain_01/band_chain_summary.txt)
- **Met-A against the atlas through the one command, two independent monocyte series (GRP-014)** — _development_  
  Healthy monocytes of two independent laboratories, read against IAM-Atlas v2.1 and tared against healthy monocytes on their own slide, all read Normal, and a planted 1 % loss stands out in both.  
  _Why it matters:_ Met-A against the atlas would let one reference serve every cell type.  
  [the record](../doors/DEV_METAA_ATLAS_01.md)
- **Every cell in a mix, and one blood draw (GRP-015, GRP-016)** — _development_  
  The one command now reads every cell type of the atlas in one run, scores Met-A for each cell it finds, reads sequencing values with a read-count correction, and reads a whole blood draw (white cells and plasma) as one record. Nine known mixtures of tissue DNA in blood were found at the right sizes.  
  _Why it matters:_ A single blood draw read for every cell in it is the goal the instruments were built toward.  
  [the record](../doors/DEV_ONE_DRAW_01.md)
- **The information sphere, with each site's level taken out (ATL-046)** — _synthetic only_  
  A construction that removes each site's methylation level before the geometry passed its synthetic test; on the real atlas it met two of three checks, and the next test asks the right question with level-matched lines.  
  _Why it matters:_ A map of how sites behave, not where they sit, is the second sphere.  
  [the record](../doors/DEV_SPHERE_01.md)
- **Every globe layer has a working slider: the audit after the fix (ATL-063)** — _audit_  
  A browser audit of every layer of every globe on the live site: every layer has a working slider, and every change layer goes dark at the right end on a healthy blood. The release check now tests every layer.  
  _Why it matters:_ A picture a researcher cannot trust is worse than none.  
  [the record](../doors/DEV_SPHERE_01.md)
- **The X and Y in IAM-A's held error (OTH-080, DEV-IAMA-SEX-01)** — _audit_  
  Counting IAM-A's held error with the X and Y left out moves IAM-A by a fraction of a percent, well inside the band; the line and band are kept.  
  _Why it matters:_ A reader may assume the X was not handled; this shows it was.  
  [the record](../manual/decoder_text.md)
- **Colon's controls matched on the slide (ATL-070, DEV-TISSUE-GLOBE-01 run 3)** — _development_  
  Matching colon controls on the same slide changes nothing: two healthy people's colon differs nearly as much as a tumor differs from its own normal, which is why the person's own normal tissue is the reference that counts.  
  _Why it matters:_ It says which reference a tissue reading needs.  
  [the record](../doors/DEV_TISSUE_GLOBE_01.md)
