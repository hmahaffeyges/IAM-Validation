# chain/ - the running code (chain v3)

**What this folder is.** The instrument: everything a chain v3 run executes, the frozen inputs it reads, the test data its release
check runs on, the toolkit stages that are built but not yet wired in, and the generators that keep the documents true to it.
Chain v3 is the only engine. The class-floor engine (v2: class floors, tiers, disease matching, its deconvolver, report builder,
SOP and manual) was retired on 2026-10-03 and is archived privately.

Procedure: [`../sop/MethylPhys_CPG_SOP_v3.md`](../sop/MethylPhys_CPG_SOP_v3.md). Operator chapter: [`../manual/OM_v3_neutrophil_chain.md`](../manual/OM_v3_neutrophil_chain.md).
Step order **as the code calls it**: [`../doors/CHAIN_SEQUENCE.md`](../doors/CHAIN_SEQUENCE.md), generated by [`build_chain_sequence.py`](build_chain_sequence.py) - that file is the authority.

## The live path (one specimen, `MethylPhys_Interface/run_sample.py`)

| stage (SOP 2b) | what it does | file |
|---|---|---|
| 0 intake | arrival, manifest, integrity hash, control probes, detection, bead count, call rate, platform coverage, sex, decision gate; a QUARANTINE stops the run (exit 2) before anything is scored; thresholds from `Runtime Matrices/Intake/intake_thresholds_v1.json` | [`stage_0_intake.py`](stage_0_intake.py), [`stage_0_1_qc_handoff.py`](stage_0_1_qc_handoff.py) |
| 1 calibration | raw IDAT pair to beta (methylprep noob), probes at background removed | [`stage_1_idat_calibration.py`](stage_1_idat_calibration.py) |
| platform check | EPIC v1 only (array type from Stage 0; more than 700,000 probes; no EPIC v2 names) | [`conductor_v3.py`](conductor_v3.py) `platform_refusal` |
| 2 composition, blood groups | NNLS over the 963 markers of the 8 purified EPIC blood groups | `conductor_v3.stage_a_composition` |
| 5 Met-A | neutrophils: isolated cells against their healthy reference; whole blood against the composition-matched healthy expectation | `conductor_v3.stage_m_isolated`, `stage_m_blood`; [`stage_m_met_a.py`](stage_m_met_a.py) |
| 6 C-score | clustering of the departures in genomic order (no band yet) | `conductor_v3.stage_mc_cscore` |
| 7 IAM-A | single-molecule reading from a `.pat` file or a per-site table (pipeline required) | [`stage_q_iam_a.py`](stage_q_iam_a.py) |
| 8 same-run tare | A_rel against at least 3 same-run healthy references | `conductor_v3.stage_t_tare` |
| 9 noise gate | noise index N; the gauge state is withheld above N_max when untared | `conductor_v3.noise_index`, `noise_gate` |
| 13 report | one HTML page and the JSON bundle; one ledger row per run | [`MethylPhys_Interface/report_v3.py`](MethylPhys_Interface/report_v3.py) |

**Frozen inputs** (`Runtime Matrices/`): `Met_A_Floors/` (metA_floors_v1_3.json, metA_floors_v1_3_loo.csv, neutrophil_reference_v1_1.json,
blood_composition_EPIC_v1.json, noise_sites_EPIC_v1.json, noise_gate_EPIC_v1.json), `Runtime Matrices/IAM_A_Positions/iama_positions_v1.json`,
`Runtime Matrices/Intake/intake_thresholds_v1.json`. Their sha256 are in [`FROZEN_INPUTS_v3.json`](FROZEN_INPUTS_v3.json); every bundle records a short hash of each under `versions`.

**Toolkit** (stages 3, 3b, 3c, 4, 10, 11, 11b, 12, 12b): built, importable, not part of any reading - [`TOOLKIT.md`](TOOLKIT.md).

## Run

```
python3 chain/MethylPhys_Interface/run_sample.py --grn S_Grn.idat.gz --red S_Red.idat.gz --specimen "whole blood" \
  --array-type EPIC_v1 --sex F --age 52 --id S001 --out reports/S001.html
# --sex and --age are optional (recorded when given; NOT_DECLARED otherwise). Specimens: whole blood or isolated neutrophils.
# pass 2 of a batch, with the same-run healthy references from pass 1:
python3 chain/MethylPhys_Interface/run_sample.py ... --slide-ref-table refs.csv
```

Every run writes the **report** (`--out`), the **bundle** beside it (`_bundle.json`) and one **ledger row** (`evidence_ledger.jsonl`, or `--ledger`).
`--covariate key=value` is recorded in the custody record, the bundle and the ledger, never in report prose.

## Check and build

- [`release_check_v3.py`](release_check_v3.py) - frozen-input hashes, static scans, v3 end to end on the bundled IDATs in `TEST_DATA/idats/`,
  a constructed whole-blood specimen and a constructed sequencing table, and the manual build. Exit 0 only when every check passes
  ([`../kit/release_check.py`](../kit/release_check.py) runs it).
- [`build_all.py`](build_all.py) - regenerates the chain sequence, the manual, the repository inventory, the RUNBOOK block and the folder READMEs.
- [`guarded_push.sh`](guarded_push.sh) - canon check, build_all, release check, then commit and push.
- Environment: [`requirements.txt`](requirements.txt) (Python 3.11, methylprep 1.7.1, numpy 1.26.4, pandas 1.5.3).
