# manual

The Official IAM Operations Manual: Instrument Diagnostics and Chain Decoder, for chain v4. The deep dive: every stage, gate and function of the chain in the order it runs, how each was built and tested, and what to do when the chain stops. How to run the chain is the Official IAM Chain Operator Guide (`../sop/`). One live version, built from the files that hold its content.

| file | |
|---|---|
| [`MethylPhys_CPG_Operations_Manual.pdf`](MethylPhys_CPG_Operations_Manual.pdf) | the built manual: the Chain Decoder, instrument diagnostics, and the chain step by step |
| [`OM_v4_decoder.md`](OM_v4_decoder.md) | the Chain Decoder, generated by `build_decoder.py` from `decoder_text.md` (the explanations) and `decoder_inventory.json` (read from the code and the traced runs, `decoder_inventory.py`); a push is refused when a chain function has no entry |
| [`OM_v4_chain.md`](OM_v4_chain.md) | instrument diagnostics for chain v4: before a run, reading the report, when the chain stops |
| [`build_manual_v4.py`](build_manual_v4.py) | builds the PDF from `OM_v4_decoder.md`, `OM_v4_chain.md` and `../doors/CHAIN_SEQUENCE.md` (`python3 build_manual_v4.py`) |
| [`OM_v3_neutrophil_chain.md`](OM_v3_neutrophil_chain.md), [`build_manual_v3.py`](build_manual_v3.py) | the chain v3 operator chapter and its builder, kept as the record of how the chain was built |
