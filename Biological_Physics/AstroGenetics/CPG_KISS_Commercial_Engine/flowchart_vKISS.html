HARD-WON LESSONS — read before touching the deconvolver

LESSON-MATRIX-02 (2026-06-29): The disease matrix is the cellular comparison engine — per-disease signatures scored against the patient's per-cell A-departures by directional concordance (direction, not magnitude: the cohort supplies the arrow, the A-score supplies the size). Its patient-safety gate is the cell-of-origin specificity rule: a solid-tissue cancer is SPECIFIC only when one of its own origin cells is actually present. From whole blood, where the tissue is absent, a cancer matched only on shared immune cells is NON_SPECIFIC_GENERIC — the generic stress axis wearing the disease's name. This gate is driven by disease_origin_cells.json; if that file is missing the gate silently fails and solid cancers get named off a head cold. Verify the origin map loads.

LESSON-DECONV-01 (2026-06-21): The global NNLS deconvolver and the A-scoring are correct — the A-scorer scored all 115 cells cleanly across 460 GSE51032 samples in VAL. The real-IDAT inflation (absent cells like stem_pluri reading 0.44 instead of 0.14) was traced to a missing Stage 1 calibration: the chain was fed raw decoder β = M/(M+U+100) with no dye-bias or probe-type normalization, leaving β compressed (methylated peak ~0.85 not ~0.95), which inflates every A-score — worst where the true score is lowest. The earlier "reference mismatch / blood β fits atlas 2.6× worse" framing was wrong; calibrating the IDAT to noob β restores the correct readings (stem_pluri 0.14, granulocytes 1.18 — both VAL-matched).

A hierarchical within-class refinement was built and validated — it invents signal (HSC/GMP/neurons; MAE 0.271 on pure monocytes), failed composition-recovery validation, and does not ship.

Binding: the cell tier is INDICATIVE by design in v0.1; the two-tier report (class reliable / cell indicative) is the validated honest posture. Richer per-cell resolution is reference/atlas work, never a solver swap, and must clear a composition-recovery + null suite before production. "More cells resolved" is only progress if resolved correctly.

Stage 1 — Calibration & β (noob)

  1. The patient's IDAT pair is calibrated to β with the standard per-sample preprocessing: dye-bias correction + probe-type normalization (noob). This uses only the patient's own on-chip control and out-of-band probes — no cohort, no reference matrix, nothing external.
  2. Array type (450k vs EPIC) is auto-detected from the IDAT bead-address count; the operator drops any IDAT pair and the step adapts. No manifest file is supplied — methylprep manages its own manifest cache.
  3. Output β = the noob-calibrated methylation value per CpG. (The raw decoder β = M/(M+U+100) with no normalization is retired from the chain — it left the methylated peak compressed ~0.85 and inflated every A-score; the Stage 1 calibration spec.)
  4. β range and distribution sanity.

Stage 2 — Deconvolution (Walther alone — composition/presence, gates no call)

  1. Load the rebuilt atlas — 115 cells / 8 classes, with the *_mean / *_sd MCMC posteriors.
  2. Walther NNLS solve → class fractions (constrained: f ≥ 0, Σf = 1; the production composition layer). This is the only deconvolver in the lean chain. NILC and the agreement AND-gate are cut (deferred shelf) — they collapsed on correlated blood mixtures and deleted correct calls.
  3. The deconvolver answers one question only: what cells are in the mix. It resolves the immune compartment so the per-cell layer reads resolved cells, not bulk-mixture background (an unresolved cell's markers read a blend, not that cell's architecture). It never gates a detection call — the call is the A-score and the derived hull (Stage 4 / verdict).
  4. Two tiers, by design. Tier 1 — 8 class fractions: the reliable composition answer. Tier 2 — 115 cell-type fractions: finer decomposition, INDICATIVE only — "weakly separable in IAMAtlas v0.1." NNLS is sparse, so Tier 2 resolves a handful of cells per sample; expected v0.1 behaviour. Never gate anything downstream on Tier 2.
  5. class_present from the bootstrap CI lower bound (> numerical zero). The per-cell fraction sets cell-level CONFIDENCE (reliable vs indicative), never a scoring gate. Shed organ cells are the exception — they are detected by A-score, not fraction (a cortical neuron at 1.292% reads d=+1.96; the fraction nulls it, the A-score catches it), so the ≥3% composition floor used by the architectural verdict (below) never applies to them.
  6. Attach a CI to each fraction from the atlas posteriors.

Stage 4 — A-score (architectural state + brightness CI)

  1. Load the per-class identity CpGs — the genome-representative loci where a healthy cell of the class sits at its characteristic methylation (mean β ≈ the class value, e.g. immune ≈ 0.73). Not the one-vs-rest discriminative markers (those are bimodal — half locked high, half low — so their mean β collapses toward 0.5 and the gauge falsely pins the ceiling; the discriminative markers belong to the separation / disease-matching layer, never to this gauge), and not the most-methylated loci (those drive healthy below the floor).
  2. Load the 8 frozen H_min floors (the Mahaffey Numbers), one per class.
  3. Per-class A = H(β_mean) / H_min(class) — take the one mean β across the class's identity loci, then the Shannon entropy of that single mean (entropy-of-mean / H of one β, exactly as the GAPE suite defines it; never mean-of-entropies — that is the separation statistic, a different instrument for disease-matching).
  4. EVERY cell type in a present class is A-scored (run-everything doctrine), each on its own class's H_min. This is INDEPENDENT of the deconvolution fraction — the fraction sets confidence (reliable vs indicative), it NEVER gates scoring. The only thing that NULLs a cell A-score is insufficient marker coverage (INSUFFICIENT_MARKERS). Do not gate on a per-cell fraction floor — that collapses the cell tier and violates §655.
  5. Floor-gate (whole blood — the only substrate we draw). Every class the deconvolver resolves at or above ~1% is A-scored, so a tissue cell that breaches into blood (the glioma cortical neuron at 1.292%) is scored, not just flagged — detection is by A-score, never gated by cell type. A class the deconvolver does not detect reads NOT_ASSESSABLE_IN_SUBSTRATE. A floor-gate marks any tile scored below its class H_min as an absent cell reading background: flagged below_floor, never counted as a positive organ flag. (cfDNA/plasma is not drawn — that tissue-of-origin lane is left to GRAIL; see shelf.)
  6. Two tiers: class-level A-scores are RELIABLE (the call); cell-level A-scores are the INDICATIVE tier (weakly separable in v0.1). A cell the deconvolver does not resolve reads the bulk mixture at its one-vs-rest markers and can pin near the ceiling or below its floor — a low-confidence background read, flagged, never a finding.
  7. Load the 8 brightness files (per-class per-CpG mean/sd/ci) and propagate the per-CpG sd through H/H_min → a real CI on every A.
  8. The scale, per class — three directions, age-matched. A = 1.0 is the architectural commitment line (the H_min reference value), not where healthy sits. Healthy reads in the NORMAL band ≈ 0.95–1.00, age-matched, drifting up toward 1.0 across the lifespan (the per-class × age baseline table is the reference). Above the band: MARGINAL ≥ 1.01 → DETECTABLE ≥ 1.05 → URGENT ≥ 1.07 → FLOOR BREACH ≥ 1.10, with the ceiling at 1/H_min (immune floor 0.839, ceiling 1.192). Below 0.95: INVERSION — a legitimate identity-loss finding (seminoma reads 0.67, senescence, aged HSC), not a data error. A below-band read is only a data problem when the whole sample is un-normalized (the input-scale guard catches that).
  9. HOW THE A-SCORE IS / IS NOT CALCULATED. The gauge is A = H(one mean β) / H_min, read against the age-matched NORMAL band. NEVER mean-of-per-CpG entropies (that is the separation statistic for disease-matching, a different instrument). NEVER over one-vs-rest discriminative markers (bimodal → false ceiling). NEVER forced to 1.0 (healthy ≈ 0.95, age-matched). For cfDNA / plasma, score on the frag / wps substrate floors, never the methyl floor.

Detector · the AD directional read — and a hard-won lesson

Stage 4.5 — Bidirectional decomposition (composition-independent)

  1. What it does. For each class that has a sealed directional panel, it z-scores every panel CpG against that CpG's frozen reference mean/SD and multiplies by the CpG's frozen direction (+1 up-in-disease, −1 down-in-disease), then averages to one signed composite. Positive = the patient moves the disease way; negative = the patient moves the healthy way. The sealed VAL-051 Rule A 7-CpG immune panel is the v1.0 anchor (AD-direction); the other seven classes return NO_PANEL until their VALs seal.
  2. Why it must exist — the trouble its absence caused. AD's immune signal is bidirectional: some CpGs go up, others down. The pooled A-score, being entropy, is symmetric around β=0.5 and cancels it (VAL-050: d=+0.077, null). The natural fallback — running AD through the residual matched filter (S1 below) — is worse than null: it false-fires. The matched filter measures departure from a fixed whole-blood baseline, and a patient's own cell composition shifts β away from that baseline in a patterned way. On AD that pattern aligns with the disease map, so the filter fired AD positive at ρ ≈ +0.55–0.60 on healthy blood — sick and well alike. A healthy 58-year-old read as AD.
  3. Why this stage cannot leak that way. The reference here is frozen per CpG, not a whole-blood composition baseline, so a patient's composition has nothing to leak into. It is composition-independent by construction. That is the entire reason AD is detected HERE and is deliberately removed from the matched-filter sweep (S1 now sweeps breast + immune-alarm only). The same healthy 58M now reads composite −0.102 (healthy direction), not AD.
  4. How it was lost — so we never lose it again. This stage was DESIGNED in (config keys present, listed in-scope) but Route C “stood down in the lean v1 build,” and the two module files were never placed in the run folder. With no Stage 4.5, the chain silently fell back to the matched filter for AD — that absence is the entire origin of the false-positive bug. The files are now placed and the stage is wired into run_pipeline. If this node is ever empty again, AD detection is broken.
  5. Honest scope. The sealed Rule A reference is AIBL-trained: it discriminates within AIBL (AD +0.329 vs HC +0.079) but its frozen reference does not transfer to other-platform cohorts (GIFT AD reads −1.228). The flag only fires on a clear AD-direction move (|composite| > 0.40), so a non-transferring cohort yields a miss, never a false alarm. The physics cure — re-anchor the reference to the IAMAtlas A-score departure and keep only the direction from the cohort — is the open VAL-053 question.

Detector · Mode 1 — architectural

Stage 8 · Route B — Disease-signature concordance

  1. Assemble the patient's derived A-departure vector — how far each scorable cell has walked from its healthy reference (A−1.0).
  2. Load the disease matrix — 81 signatures spanning 52 disease cores across their phases (10-yr-prior, 5-yr) and states. For a whole-blood sample the whole-blood subset is scored (42 signatures in our GSE42861 test). The one-stop comparison sheet; all cards folded in.
  3. Match by scale-invariant cosine — the angle between the patient's departure and each signature. Units cancel: no σ, no z-shift, nothing standardizes the patient against a population. Direction agreement is the coarse gate; cosine shape is the fine discriminator (it is what separates aging from Alzheimer's — same direction, different proportions).
  4. Works on every class detected at or above ~1% (Walther OR NILC). In normal whole blood that is dominated by the immune class, where most field-effect and systemic disease writes its signal — but a breached tissue class (the glioma cortical neuron, terminal) is scored and enters the vector too. This is the workhorse for most of the 52.
  5. Reports resemblance, not probability; the calibrated magnitude that turns resemblance into a stage accrues from real patients, in our own derived A-units.
  6. Flag may fire on either deconvolver — a signal NILC-raw surfaces but Walther floored still counts.

Detector · Mode 2 — cell-of-origin

Stage 8 · Mode 2 — Presence: a cell that shouldn't be here

  1. A different test entirely: not architecture, but a cell circulating in blood that should not be there. The shed-cell premise — the family of signal GRAIL screens for.
  2. The A-score is the sensitive front end — VAL-090: the deconvolver fraction nulled the glioma cortical-neuron signal; the A-score caught it (d=+1.96, and d=+5.47 on the strong cohort). A terminal/secretory cell reading above its class floor in whole blood is the shed signal, at any fraction. (NILC-raw surfacing is deferred to the shelf; the A-score makes it unnecessary.)
  3. Flag any non-blood class reading above its class floor in whole blood (detect ~1%, VAL-090) — this path is never gated by the ≥3% composition floor; a 1.292% cortical neuron is exactly the signal.
  4. Blood-brain-barrier cells (cortical neurons, glia, oligodendrocytes) — red flag the moment they are present: they crossed a physical barrier to be here. And once present they are also A-scored (the glioma cortical neuron, +1.96) — presence is the alarm, the A-score is added signal, not discarded. Refer.
  5. Other shed cells (epithelial) — presence plus A-score: present with a normal A is benign turnover; present with an abnormal A is concerning. The A-score is the discriminator.
  6. This barrier-breach alarm is a whole-blood test (the substrate we draw): a brain cell in peripheral blood crossed a physical barrier to be there. (We do not draw plasma; cfDNA tissue-of-origin is GRAIL's lane.)
  7. Flag-and-refer to a specialist, never a diagnosis. Baseline shed quantities calibrate from real patients.

Verdict gate — the derived-hull architectural alarm + the matrix flag

Layer 0 — derived-hull global departure (the primary verdict). Sum the standardized departure (A−1.0)/σ over the classes that are present (composition) and off the healthy band [0.95,1.04); under the healthy floor this ~ χ²(n), so the threshold is analytic (p95/p99), n-adaptive — no cohort. Within band → the report reads healthy and every Route-B resemblance is demoted as coincidence (the documented healthy-58M verdict: d=0.0, "resemblance, not a probability"). Beyond band → a real architectural departure, named by which class drove it (the 67F verdict: d beyond band, driven by stem_adult 1.101). Shed organ cells (Mode 2) and the AD directional panel (Stage 4.5) fire independently of this hull.

WITHIN BAND & no flag → report reads healthy (resemblances demoted) BEYOND BAND or matrix flag or BBB breach → run the second chain
Second chain · confirmation only BUILT. Independent: runs only when a flag fires, never mutates the primary. The disease matrix (Route B) remains the primary detector; the residual matched filter confirms; the directional class signal and literature anchor qualify. One integrated verdict is appended to the single report.
S1

Residual-map matched filter (SOP 8.2) the detection instrument

  1. For the flagged disease, route to its sealed residual map: breast → breast map, immune-class diseases → the immune cross-disease universal alarm. AD is NOT routed here — its signal is bidirectional and composition-aligned, so this filter false-fired it on healthy blood; AD is detected at Stage 4.5 instead. More maps over the coming months.
  2. Patient per-CpG departure from the derived atlas baseline (the whole-blood class mean — derived, no cohort), versus the map's signed Cohen's d — the direction the disease moves each CpG, fixed in advance from validated case/control cohorts.
  3. Pearson correlation between the two, with a 95% Fisher confidence interval. Fires when the interval is clear of zero in either direction — elevation or suppression both count. The same matched-filter statistic used in gravitational-wave and CMB searches. Offset-robust only against a uniform baseline shift (Pearson centres both vectors), which cancels cleanly — this is why breast and the immune alarm are safe here. It is NOT robust against a patterned shift: a patient's cell composition moves β in a structured way that can align with a disease map, and that alignment is exactly what false-fired AD at ρ ≈ +0.6 on healthy blood. Use this instrument only where the signal is broad enough that composition does not align with it (breast case +0.10 vs control −0.27 separates cleanly).

Trajectory — from the second draw on per-cell, the same patient against themselves

  1. Each draw saves a small derived baseline — per-cell A-scores with their reliability tier, the matrix-column departure vector, and the global departure. No raw β.
  2. On the next draw, compare cell by cell: the per-cell delta is the unit — each cell's dilution offset is shared at both draws and cancels in the subtraction, so a class can sit flat while the cells beneath it move in opposite directions. Deconvolver-resolved cells lead; indicative cells follow as a softer read; bulk pseudo-cells (whole_blood, PBMC) are excluded.
  3. Rotation toward the flagged signature: the whole departure vector's cosine to the disease signature, prior vs now — the strongest single indicator of where the architecture is headed — plus self-alignment to the prior draw and the global-departure trend.
