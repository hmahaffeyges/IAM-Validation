The chain we follow — every step, in order

This is the reference both walther_clinical.py and the report builder get checked against. Primary chain stays KISS and runs on every patient. A flag from the disease matrix — and only a flag — triggers a separate confirmation chain. Every value carries a CI from the atlas's own MCMC posteriors.

Drawn from the live AstroGenetics/CPG_CMB_v1 folder — verified paths and runtime steps, 8 brightness files (per-class per-CpG mean/sd/ci), 246 atlas posterior columns.

Build the folder from the manifest below, drop in the IDAT pair + questionnaire.json, then run python walther_clinical.py (or --folder <path>). HARD-WON LESSONS — read before touching the deconvolver

LESSON-DECONV-01 (2026-06-21): The global NNLS deconvolver and the A-scoring are correct — the A-scorer scored all 115 cells cleanly across 460 GSE51032 samples in VAL. The real-IDAT inflation (absent cells like stem_pluri reading 0.44 instead of 0.14) was traced to a missing Stage 1 calibration: the chain was fed raw decoder β = M/(M+U+100) with no dye-bias or probe-type normalization, leaving β compressed (methylated peak ~0.85 not ~0.95), which inflates every A-score — worst where the true score is lowest. The earlier "reference mismatch / blood β fits atlas 2.6× worse" framing was wrong; calibrating the IDAT to noob β restores the correct readings (stem_pluri 0.14, granulocytes 1.18 — both VAL-matched).

A hierarchical within-class refinement was built and validated — it invents signal (HSC/GMP/neurons; MAE 0.271 on pure monocytes), failed composition-recovery validation, and does not ship.

Binding: the cell tier is INDICATIVE by design in v0.1; the two-tier report (class reliable / cell indicative) is the validated honest posture. Richer per-cell resolution is reference/atlas work, never a solver swap, and must clear a composition-recovery + null suite before production. "More cells resolved" is only progress if resolved correctly.

Stage 1 — Calibration & β (noob)

  1. The patient's IDAT pair is calibrated to β with the standard per-sample preprocessing: dye-bias correction + probe-type normalization (noob). This uses only the patient's own on-chip control and out-of-band probes — no cohort, no reference matrix, nothing external.
  2. Array type (450k vs EPIC) is auto-detected from the IDAT bead-address count; the operator drops any IDAT pair and the step adapts. No manifest file is supplied — methylprep manages its own manifest cache.
  3. Output β = the noob-calibrated methylation value per CpG. (The raw decoder β = M/(M+U+100) with no normalization is retired from the chain — it left the methylated peak compressed ~0.85 and inflated every A-score; the Stage 1 calibration spec.)
  4. β range and distribution sanity.

Stage 2 — Deconvolution (two methods in parallel)

  1. Load the rebuilt atlas — 115 cells / 8 classes, with the *_mean / *_sd MCMC posteriors.
  2. Load the per-class markers.
  3. Walther NNLS solve → class fractions (constrained: f ≥ 0, Σf = 1; the production layer).
  4. NILC solve in parallel → independent fractions (unconstrained GLS, inverse-variance weighted by the posterior SD). Different math, so its agreement means something — the Planck Commander/NILC discipline. Because it does not floor at the simplex boundary, it can surface a faint signal Walther zeroes out (the glioma-terminal case).
  5. Cross-method gate: compare the two at the inference layer; agreement raises trust, divergence is a documented signal to investigate, not an error.
  6. Two tiers, by design. Tier 1 — 8 class fractions: the production answer, RELIABLE, the call. Tier 2 — 115 cell-type fractions: finer decomposition within each class, INDICATIVE only — "weakly separable in IAMAtlas v0.1; trust class_fractions" (deconvolver docstring). NNLS is sparse, so Tier 2 often resolves only a handful of cells per sample; that is expected v0.1 behaviour, not a bug. Never gate anything downstream on Tier 2.
  7. class_present from the bootstrap CI lower bound (> numerical zero). The per-cell fraction sets cell-level CONFIDENCE (reliable vs indicative), never a scoring gate.
  8. Attach a CI to each fraction from the atlas posteriors.

Stage 4 — A-score (architectural state + brightness CI)

  1. Load the per-class marker CpGs — the class markers from the celltype-markers artifact, aggregated to class (union of the class's cell-type marker pools). Not the most-methylated loci: those drove healthy below the floor and produce impossible scores.
  2. Load the 8 frozen H_min floors (the Mahaffey Numbers), one per class.
  3. Per-class A = H(β_mean) / H_min(class) — mean β across the class markers first, then entropy of that one mean (entropy-of-mean, never mean-of-entropies).
  4. EVERY cell type in a present class is A-scored (run-everything doctrine), each on its own class's H_min. This is INDEPENDENT of the deconvolution fraction — the fraction sets confidence (reliable vs indicative), it NEVER gates scoring. The only thing that NULLs a cell A-score is insufficient marker coverage (INSUFFICIENT_MARKERS). Do not gate on a per-cell fraction floor — that collapses the cell tier and violates §655.
  5. Two tiers: class-level A-scores are RELIABLE (the call); cell-level A-scores are the INDICATIVE tier (weakly separable in v0.1). A cell the deconvolver does not resolve reads the bulk mixture at its one-vs-rest markers and can pin near the ceiling or below its floor — a low-confidence background read, flagged, never a finding.
  6. Load the 8 brightness files (per-class per-CpG mean/sd/ci) and propagate the per-CpG sd through H/H_min → a real CI on every A.
  7. The scale, per class: A = 1.0 is the healthy reference; the floor is the class's own H_min (e.g. immune 0.839, terminal 0.773) and the ceiling is 1/H_min. A cell can be driven down toward its floor and still hold identity; a value below H_min is impossible for a present cell, so the report flags that as a data problem rather than a reading. Verified: healthy whole-blood immune A = 1.035, glioma 0.970 — both on-scale.

Detector · Mode 1 — architectural

Stage 8 · Route B — Disease-signature concordance

  1. Assemble the patient's derived A-departure vector — how far each scorable cell has walked from its healthy floor (A−1.0).
  2. Load the disease matrix — 81 signatures spanning 52 disease cores across their phases (10-yr-prior, 5-yr) and states. For a whole-blood sample the whole-blood subset is scored (42 signatures in our GSE42861 test). The one-stop comparison sheet; all cards folded in.
  3. Match by scale-invariant cosine — the angle between the patient's departure and each signature. Units cancel: no σ, no z-shift, nothing standardizes the patient against a population. Direction agreement is the coarse gate; cosine shape is the fine discriminator (it is what separates aging from Alzheimer's — same direction, different proportions).
  4. Works only on cells abundant enough to read their own loci — in whole blood that is essentially the immune class, where most field-effect and systemic disease writes its signal. This is the workhorse for most of the 52.
  5. Reports resemblance, not probability; the calibrated magnitude that turns resemblance into a stage accrues from real patients, in our own derived A-units.
  6. Flag may fire on either deconvolver — a signal NILC-raw surfaces but Walther floored still counts.

Detector · Mode 2 — cell-of-origin

Stage 8 · Mode 2 — Presence: a cell that shouldn't be here

  1. A different test entirely: not architecture, but a cell circulating in blood that should not be there. The shed-cell premise — the family of signal GRAIL screens for.
  2. NILC-raw is the sensitive front end: its unconstrained fit surfaces faint shed signal the constrained solve floors to zero (the glioma terminal case, 1.26%).
  3. Flag any non-blood class present in whole blood above the detect_floor (1%, VAL-090).
  4. Blood-brain-barrier cells (cortical neurons, glia, oligodendrocytes) — red flag on presence alone, regardless of quantity or A-score. They crossed a physical barrier to be here. Refer.
  5. Other shed cells (epithelial) — presence plus A-score: present with a normal A is benign turnover; present with an abnormal A is concerning. The A-score is the discriminator.
  6. Flag-and-refer to a specialist, never a diagnosis. Baseline shed quantities calibrate from real patients.

Patient report — cell-centric

  1. Per-cell A-scores are the body of the report. Every cell present in the blood is scored on its own class's H_min floor. The class-level composition table and the class-level architectural-state section are not shown — the report is the cell-level fingerprint, not class summaries.
  2. Departure-ranking chart of the resolved cells: elevated bars right, suppressed left, 1.00 = healthy baseline, 95% CI whiskers, bold border = deconvolver-resolved (reliable). Cells below their class H_min floor are dropped (impossible reads); suppressed-but-above-floor cells are kept (a real measurement).
  3. Non-cell aggregates (whole_blood, PBMC, buffy_coat, …) are filtered out of the per-cell display — they are reference profiles, not cells.
  4. Mode 1 architectural concordance (with the specificity gate — a generic myeloid shift reads as "non-specific systemic myeloid pattern", not a named leukemia) + Mode 2 cell-of-origin presence (NILC-raw) + honest limits.
  5. Writes CPG_report_<patient>_<UTC>.html beside the inputs.

S1

Stage 5 — Global departure (Mahalanobis) the adjudicator

  1. Take the present-class A-score vector — the reliable tier (the 8 class aggregates, not the 115 per-cell scores: rare cells are naturally diluted below the floor in bulk substrate and cannot be compared to it).
  2. Presence gate: a class counts only if it is genuinely present (abundance ≥ 3% — a trace fraction is reading background, not architecture) and actually outside the derived NORMAL band [0.95, 1.04). A class inside the band contributes zero; a suppressed non-substrate class (e.g. stem_pluri or terminal in blood) is absence, not departure, and is excluded with its reason recorded.
  3. Band-relative distance from the derived healthy band (σ=0.02 from the NORMAL tier band, diagonal Σ — derived, no cohort): only the part outside the band counts.
  4. χ² test on d²: is the global architecture beyond the healthy band, and which present classes drive it.

Build the patient report

Trajectory — from the second draw on per-cell, the same patient against themselves

  1. Each draw saves a small derived baseline — per-cell A-scores with their reliability tier, the matrix-column departure vector, and the global departure. No raw β.
  2. On the next draw, compare cell by cell: the per-cell delta is the unit — each cell's dilution offset is shared at both draws and cancels in the subtraction, so a class can sit flat while the cells beneath it move in opposite directions. Deconvolver-resolved cells lead; indicative cells follow as a softer read; bulk pseudo-cells (whole_blood, PBMC) are excluded.
  3. Rotation toward the flagged signature: the whole departure vector's cosine to the disease signature, prior vs now — the strongest single indicator of where the architecture is headed — plus self-alignment to the prior draw and the global-departure trend.
