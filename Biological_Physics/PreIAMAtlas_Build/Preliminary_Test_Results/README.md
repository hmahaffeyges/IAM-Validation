# Preliminary Test Results

> **STUB — full README in progress.**

Evidence reports and VAL runs from the pre-IAMAtlas-build phase. The name is deliberate: these are **preliminary** results from the foundational work (testing whether IAM's law applies to the methylome and learning the disease-methylation language) — they are not presented as final, prospectively validated clinical claims.

See `../README.md` for the two governing principles (derived-not-comparison; no foregrounds subtracted).
