# PREREG — LAB-ZERO-01: can the per-lab offset be predicted from the array's own control probes?

**Sealed 2026-09-20 before any control-probe intensity was read.** Owner H. W. Mahaffey · Analyst Claude Science.
**Question.** Three Stage-1 cohorts on the Roadmap scale carry per-cohort constants in mapped immune A (Uppsala 0 / Karolinska +0.018 / Munich −0.030, flat across age). Are those constants predictable from the 850 Illumina control probes on each array (staining, extension, hybridisation, bisulfite conversion I/II, specificity, non-polymorphic, negative, norm A/C/G/T, target removal), i.e. from what the array records about its own processing — so that no per-lab healthy-control panel is needed?
**Data.** All arrays already on disk: GSE87571 (732), GSE42861 controls (335), GSE125105 controls (210). Per-sample features = log2 mean intensity per (Control_Type × channel) summarised per type (≈ 30 features), plus overall Grn/Red medians and their ratio. Target = mapped immune A (per sample) with the cohort mean as the quantity to recover.
**Test (fixed): leave-one-cohort-out.** Fit a ridge model A_mapped ~ control features on two cohorts (sample-level), predict the held-out cohort. **P1:** predicted cohort median offset within ±0.010 of the observed offset for each held-out cohort (three folds). **P2:** residual per-cohort constant after correction ≤ 0.010 in all three. **P3:** the correction must not shrink within-cohort biological spread: sd of corrected A within each cohort ≥ 0.8 × uncorrected sd (a model that "corrects" by flattening everyone fails). **N-perm:** shuffle cohort labels 200×; the LOCO recovered-offset must beat the 95th percentile.
**Outcomes.** Pass all → lab zero from control probes, Future Goal 0b promoted, Stage 0↔1 intensity hand-off is the implementation. Any fail → the constant is pre-analytical or otherwise not in the control probes; the per-lab healthy-control panel (CLSI EP28) is the standard, recorded as such. Either result is written as found.
