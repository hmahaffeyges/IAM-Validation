## Names in use

| name | status | definition |
|---|---|---|
| IAM's law | current | Every irreversible transition from quantum superposition to classical record pays k_B T ln 2 per bit to the nearest encoding surface at the local temperature. |
| M number (M) | current | The drive ratio: drive energy over the thermal noise quantum, M = E_drive/(k_B T). Sets the operating regime; for a record held in a gap hf, M = hf/(k_B T) and its thermal floor is 1/(1+e^M). Cell: 20.94 (30.2 in Landauer units). Chips: M = E_sw/(k_B T_j) = A x ln 2 (chip gauge). The only quantity named 'Mahaffey'. Named like the Mach number: a ratio to a natural scale (drive over k_BT, as Mach is speed over the speed of sound). Not named after a person (author, 2026-10-24). |
| IAM floor | current | Synonym of H_min (the floor): the lowest error a system can hold at its temperature before thermal kicks win. |
| Informational fidelity ratio (A) | current | A = reading / the same system's healthy reading (the healthy reference), measured on the same instrument. Dimensionless; A = 1 is the system working as itself, in the middle of the gauge. Below it lies H_min, the lowest error the system can hold before thermal kicks win; nothing reads below H_min. Above 1 = more error than healthy. Cells: Met-A = mean H(beta) over identity sites / the healthy reference (purified healthy cells, same platform); IAM-A = H(eps)/(P_cell H(eps0)). Qubits: eps/eps(as built), eps = -ln(1-p). Chips: E_sw/E_sw(as built). A is never the temperature exponent n. |
| Landauer metrology | current | Measuring how far above its thermal floor an information-writing process operates, against a fixed physical zero, in any substrate. |
| the methylation report | current | The biological (genetic) application of IAM's law: the umbrella for every cellular and organismal chain. Expansion as in Issue 002: Genomic Analytical & Performance Engine. Chains under it: MethylPhys CPG (methylation, cells), the salmonid chain (in development). |
| MethylPhys CPG | current | The cell instrument: Methylation Physics, Cellular Performance Gauge. Reads cells' methylation (Met-A, IAM-A) and places them on the gauge. |
| Salmonid chain | current (in development) | The cell instrument applied to salmonids: IAM-A per fish and tissue at water temperature. Not a cellular performance gauge. |
| Met-A (Metrology A) | current | Array reading of ONE cell type in one specimen (chain Stage M): Met-A = mean over the cell's identity sites of H(beta) / H_ref(cell), H(b) = -b log2 b - (1-b) log2(1-b). H_ref(cell), the healthy reference (the gauge's middle mark, healthy = 1; not the floor H_min) = the same quantity on purified healthy cells of the same type on the same platform, through the chain's own Stage 1 (constant Met_A_floor_EPIC_neutrophil; site rule Met_A_site_rule); >= 90 % of the identity sites must be measured. Whole blood: the denominator is the composition-matched healthy expectation mean_i H(sum_c f_c mu_c,i), with the specimen's own fractions f (Stage A, EPIC blood NNLS) and purified healthy profiles mu (no group comparison; PROC-WB-NEUT-01); read at any neutrophil fraction with its own detection limit (DEV-LOWFRAC-01; no fixed fraction cut). Stage T tare: against >= 3 healthy references run the same way (same slide, else same batch), A_rel = A / median(reference A); with >= 20 reference records the noise-corrected tare A = a + b f_neu + c N (N = noise index, mean H(beta) over 48,528 fixed sites; DEV-NOISE-02). The gauge state is printed on A_rel only; without references the reading is reported as untared. Each reading carries its detection limit (smallest loss of the cell's pattern the specimen could show). Commissioned 2026-10-09 on isolated neutrophils, EPIC v1; whole blood is read and printed with the note that it has not yet been tested with Met-A; 450K and EPIC v2 refused. Normal 0.95-1.05. Information theory only; no energy content. Expansion: Informational Metrology A score. |
| IAM-A | current | Error reading on single-molecule sequencing, each sample against its own reference: IAM-A = eps / eps_pred(L). eps is the held error (isolated unmethylated calls between two methylated calls, over the interior calls of qualifying molecules: at least 6 calls, at least 80 % held), counted by chain Stage Q2; L is the sample's own loose share (share of 2,000-CpG tiles held below 70 %); eps_pred(L) = 0.040265 + 0.034625 L is the healthy self-reference line, measured once on 153 healthy samples of 56 cell types (chain/Runtime Matrices/IAM_A_SelfRef/selfref_line_v1.json). No other specimen is a reference. Normal band v1: 0.779-1.055 (band_v1.json). Before reading, the sample-shape check declines a sample whose tile distribution is outside the healthy shape of its cell type (shape_reference_v1.json). Ends on the gauge are the sample's own: full surface 0.5/eps_pred(L) (12.42 at L = 0, 6.68 at L = 1). Commissioned 2026-10-17 on healthy blood CD8 T cells, whole-genome bisulfite sequencing (COMMISSIONING_NOTE_IAMA.md); other cell types are read and printed with the note that they have not yet been tested with IAM-A. The earlier position form, H(eps)/(P_cell H(eps0)), is retired (development flag only). |
| Salmon-A | informal | Not a separate quantity: IAM-A read by the salmonid chain (body temperature = water temperature). |
| the quantum-processor report | current | Quantum computing report line. |
| the semiconductor report | current | Semiconductor report line. |
| EPLG | current | Error Per Layered Gate (IBM): the average error per gate across a 100-qubit chain running layered circuits, including crosstalk and idle errors. It is NOT the same quantity as an isolated median two-qubit error p(2Q) and must not be compared with one. |
| C-score (sky-map C-score) | current | Clustering of a specimen's residual sky map on the Met-A identity sites: c = var(sqrt(10) x the means of 10 consecutive sites in genome order) / var(z), over the site variance; C = c / c_healthy, c_healthy = 1.0103 (leave-one-out median of the six reference arrays; neutrophil_reference_v1_2.json), so healthy reads 1 on the same gauge as A. Read one-sided against the healthy band 0.877-1.152 after the same-run tare (above 1.152 is a clustered departure). Commissioned 2026-10-15 on whole blood, EPIC v1 (COMMISSIONING_NOTE_CSCORE.md). Chain v4 also draws the map on a HEALPix sphere (NSIDE 128, nested order) in the report; nothing is scored from the drawing. A cosmology map statistic, not a physics floor. On first use in papers write 'sky-map C-score'. Blocks of 50 and baseline 1.1104 were the construction before 2026-10-09. |
| H_min (cell) | retired | In the cell chain, the floor a reading is divided by. For Met-A: the cell type's reference floor on that platform (Met_A_floor_*), one per cell type, from purified healthy cells - never a class value. For IAM-A: P_cell * H(eps0), the physics floor's entropy at the cell's frozen architecture position P_cell (same read-level pipeline). |
| H_min (the floor) | current | The absolute lowest error a system can hold before thermal kicks win; below it the system no longer exists as itself. It is NOT the denominator of A and NOT 1: it sits below 1 at H_min / healthy reference. Cells: thermal kicks win against one full ATP per site, held error 1/(1+e^M) = 8.1e-10, H_min = 2.5e-8 bits (1e-7 on the IAM-A gauge, 8e-8 on Met-A, neutrophils). It is NOT the healthy reference height H_ref = H(eps0) = 0.2593 bits. Qubits: the thermal floor p_eq t_g/T1, p_eq = 1/(1+exp(hf/(k_B T))) at the temperature the qubit's record sees. Chips: the Landauer floor k_B T_j ln 2. |
| eps (gate error in nats) | current | eps = -ln(1 - p(2Q)), the two-qubit gate error expressed in nats; eps ~ p for small p. It is the qubit reading; A = eps / eps(as built). |
| One gauge (convention) | current | Every score is an error score on one gauge: A = 1 is healthy in the middle, H_min below it is the floor nothing passes, above 1 is more error; a failure point may lie on the high side (qubits: error correction fails near p = 1 %). Each domain keeps its field's form. Always quote a value with its score's name. |
| Healthy reference | current | The denominator of A: the same system's healthy reading on the same instrument. Cells: Met-A, the purified healthy cells of that type on that platform (EPIC neutrophils 0.330263 bits; constant name Met_A_floor_* kept for the chain until the SOP rename); IAM-A, the sample's own predicted held error eps_pred(L) from its own loose share (commissioned 2026-10-17; no other person enters; the earlier P_cell H(eps0) form is retired). Devices: the device as built. |
| Thermal floor (qubit) | current | The qubit H_min and the left-hand mark of the qubit gauge: IAM's Law at the temperature the record sees. p_eq = 1/(1+exp(hf/(k_B T))) for the held record; p_eq t_g/T1 for one gate of duration t_g (detailed balance). |
| H_ref (healthy reference height) | current | Cells: where healthy cells actually hold their methylated sites, H(eps0) = 0.2593 bits (E_hold 3.084 kT, measured per interior opportunity across 56 healthy cell types; about half hold better than it). Measured, not a limit; the floor is H_min. The distance from H_min to H_ref in energy is phi = 0.1473 of one ATP. |
| IAM-Atlas v2.1 | current | The reference map of 79 purified healthy human cell types: 813,951 sites, built from 21 public array and sequencing sources fitted as one Bayesian model, so every site carries a best value and a 95 % range. Commissioned use by use (COMMISSIONING_NOTE_ATLAS_V21.md). Published: fitted atlas 10.5281/zenodo.23441999; 100 posterior draws per block 10.5281/zenodo.23422688. |
| IAM-Deconvolver | current | Reads which blood cells are in a sample and in what shares (chain Stage D21), against IAM-Atlas v2.1's six-cell blood panel; commissioned on the mean share error (0.016, bar 0.03) in a laboratory it never saw. |
| Group-A | current | The group instrument (chain stage_groupa.py, commissioned 2026-10-20): each person's whole-blood Met-A, tared against healthy arrays of the same run, and the two groups' tared means compared (difference, standard error, t). Groups must be run in the same series. |
| Tare (same-run tare) | current | Dividing a reading by the median of at least 3 healthy references run the same way (same slide, else same series), so a laboratory's offset cancels: A_rel = A / median(A_refs). Met-A, the C-Score and Group-A use it. |
| Sky sphere (address sphere) | current | The globe layout every IAM map uses: every atlas site in genome order placed on HEALPix NSIDE 256, NESTED order, site i of n at pixel floor(i x NPIX / n) (atlas/tools/sky_maps_v21.py; frozen for the chain in sky_order_v21.npz). A site's place is its genome address; the information is in the color. Benefits: equal-area pixels, no edges, change along the genome shows as patches, and the sky's tools (masks, nulls, maps with uncertainty) apply. |
| Information sphere | current | In development (DEV-SPHERE-01): a globe on which a site's place comes from how it behaves, not where it sits. Each methylation level b maps to the point (sqrt b, sqrt(1-b)) on a circle of radius 1, and the distance between two states is the Fisher-Rao angle; the whole methylome lies on one high-dimensional sphere. Not adopted until its construction passes its sealed bars. |
| Globe Explorer | current | The site's page of interactive globes (IAM-Atlas v2.1 first; Met-A's purified-array reference; example samples; noise maps), drawn by the chain's one viewer (globe_viewer.py), the same code as every report's globe. Pictures, not readings: nothing is scored from a globe. |
| Noise map (posterior draws) | current | The atlas's uncertainty shown as its own pictures: the average of the first k of a cell's 100 posterior draws at every site (k = 1, 2, 4 ... 100, draws taken in turn from the four sampling chains); the map settles onto the atlas's value as k grows (atlas/tools/noise_maps_v21.py). |
| Anchor range (preliminary) | current | A whole-blood reading of the span between an array's low and high fixed-site anchors, tared on its slide, that keeps a loss spread evenly over every site, which Met-A's self-tare cancels (GRP-014, DEV-SELFTARE-03). Preliminary: read and flagged, not commissioned. |
| Hard-to-map probes | current | EPIC v1 probes whose sequence matches the genome with mapping quality under 10 or not at all (3.14 % of the array). Removing them moves no IAM instrument beyond its own repeat noise (DEV-MAPPABILITY-01, OTH-079); IAM-A's read counter already drops reads with mapping quality under 10. |
| floor | current | The least error heat allows for a mark held with the full drive: eps_min = 1/(1 + e^M), H_min = H(eps_min). Status: derived. |
| ceiling | current | One bit per site: a mark lost entirely, read as a coin flip. Status: derived. |
| baseline | current | Where a healthy cell of its kind sits between the floor and the ceiling, for every instrument (Met-A's baseline, IAM-A's baseline). One name; how its value is known is a status label: derived (from the physics, nothing estimated), calibrated (a derived form with constants measured once on healthy cells and frozen), measured (taken from reference samples), candidate (derivation written, its test not yet passed). Only the label changes when a test passes (author, 2026-10-24). Today: Met-A's baseline measured (six commissioned neutrophil arrays), its derived value a candidate (DEV-METAA-HEALTHY-01 step 3); IAM-A's baseline calibrated (selfref_line_v1.json). |
| reference | current | Only what is measured: the reference atlas (IAM-Atlas v2.1) and the healthy reference cells and arrays in it. Never the baseline. |
| The territories | current | In development (DEV-TERRITORIES-01): disorder at two fixed sets of sites the identity readings do not reach, each read on the A-score gauge against IAM-Atlas v2.1 at each site's own read count: the islands (sites every healthy cell type keeps unmarked) and the domains (marked sites some healthy cell types hold loosely). Read on every run of the one command and flagged; not commissioned until healthy samples read Normal on a sealed test. |
| Nearest-neighbor coupling | current | In development (plan 49.5): on held molecules, the pairs of neighboring CpGs that lost their mark together, over what each molecule's own length and error count give at random; 1 is independent. Recorded by chain Stage Q2 (stage_q2_selfref._coupling) on every sequencing count, beside IAM-A's held error. Not commissioned until it has a healthy reference and a sealed test. Drawn on the A-score gauge as coupling-A: the sample's coupling over the healthy coupling of its own cell type (healthy 1), from 0 (errors never neighbors) to the sample's own most clustered arrangement. |
| Met-A on sequencing | current | In development (DEV-METAA-ATLAS-CURVE-01): Met-A against IAM-Atlas v2.1 for a whole-genome bisulfite sample, with each atlas column put in sequencing units by the conversion the atlas's own build measured for the published sequencing atlas, because the atlas's array scale holds unmarked sites near 0.055 where sequencing reads 0. |
