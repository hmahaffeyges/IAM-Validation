# Security policy

Thank you for being careful and reporting security issues responsibly.

Reporting
- If you believe you've found a security vulnerability in this repository, please email:
  hmahaffeyges@gmail.com
  with subject line: [SECURITY] <short description>

What to include in a report
- Steps to reproduce (minimal PoC if possible)
- Impact and scope
- Affected versions/commit SHA
- Contact info and whether you prefer encrypted communication (PGP key)

Response policy
- We will acknowledge receipt within 3 business days.
- We will triage and, if confirmed, work on a fix and coordinate disclosure.
- If you require a vulnerability disclosure NDA or PGP, indicate it in your email.

Disclosures
- Coordinated disclosure policy: please give us 90 days to fix before public disclosure unless safety concerns require earlier notice.

Thanks — Heath Mahaffey# Security Policy
