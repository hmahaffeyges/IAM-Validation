# IAM in bits: the applications translated into computer language (scope, 2026-10-15)

**IAM is a model of how reality begins with a bit and the cost that comes with it.**

Author, 2026-10-15: "We dont need all of that. We just need to translate our applications and make the connections all of it using computer
language. We need to put everything into bits." Not a new book: the book stays the source. Manifest OTH-061.

## What it is
1. **One table per application** (cosmos, qubits, chips, cells), the same rows in each, every value in bits with its book or chain source:
   bits stored (capacity) | bits per operation | bit rate | gate error | leakage | operating point (healthy) | throttling (working too hard) |
   saturation (the ceiling) | the price per bit (k_B T ln 2 at that surface).
2. **One connections table:** each row read across all four (for example saturation: black hole, error-correction threshold, chip thermal
   limit, tumor).
3. **Credits only as a short citation** where a value is someone else's. Where a domain has no value yet, the cell says open.

## Not in it
New derivations, essays, the lineage survey. The literature check (OTH-062) stays a separate task, used only where a citation is needed.
