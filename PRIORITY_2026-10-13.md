# The order of work, and how long each step takes (2026-10-13)

Written for the author, at the pace this project has actually run: a session is a working night, and every duration below
carries the bumps we keep hitting (four lung attempts before the set was ruled unsuitable; four attempts before the IAM-A
cause test ran). Records are linked so nothing here is a claim without a source.

## What makes a physicist take the law seriously

IAM-A is one instrument reading one quantity; on its own it is not the strongest evidence for the law. What a physicist
reads first is a **parameter-free prediction that survives a change in the physics**. Four levers exist, in order of force:

| Lever | Why it carries weight | Where it stands |
|---|---|---|
| **Temperature** | The floor is set by kT, so a different body temperature must move it by a *derived ratio* with nothing fitted. A hibernator or a cold-water fish is the closest thing here to an Eddington test. | hibernation test designed (`DEV-TEMPERATURE-01` in planning, LOG 2026-10-09); salmonid reads in S3 |
| **Energy supply** | Starve the methyl supply and the reading must rise by a derived amount. | the mouse knockout met its committed window (`DEV_SAM_LEVER_01`); methionine parked for too few divisions (`DEV_METHIONINE_01`) |
| **Division rate** | Landauer's cost is paid per copy, so copy error must scale with divisions, and neurons never divide. | neuron reference rule sealed (`DEV_IAMA_NEURON_01`); passage series in hand (`GSE268145`) |
| **One floor across substrates** | The same floor for cells, chips and qubits with no per-system fitting is the 37-orders claim, and it needs no new compute, only writing. | calibrated values already exist in the QAPE and SCAPE lines |

Aging is the weakest of these: it is correlational, the literature is crowded, and no ratio can be predicted in advance.
It is reach, not proof.

## Which cancers matter most for early detection

| | Both sexes | Women | Men |
|---|---|---|---|
| Highest value | lung (largest killer); pancreatic (lethal, no screening exists) | ovarian (no screening, found late); breast in dense tissue, where mammography is weakest | prostate, where the value is fewer false alarms and avoided biopsies rather than more detection |
| Best near-term shot | colorectal: screenable, slow, and pre-cancer is visible in public data | breast | colorectal |
| Honest caution | brain: a real need, but little tumor DNA crosses into blood, so it is a later target | | |

**Therefore the order for commissioning Met-A on tissue cells: colon epithelium, hepatocytes, breast epithelium, lung
alveolar and bronchial.** Colon first, because adenomas are the only pre-cancer evidence available in public data, and
pre-cancer is the whole argument for early detection.
